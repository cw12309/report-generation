#### 乳腺专用基线与模块要点

- 模块1 病灶病变水平（核心6要素）：分类描述（肿块MASS/非肿块强化NME/囊肿/点状强化）+ ①定位（象限+钟点方向）②几何(形态/边缘) ③信号(T1/T2/DWI/ADC) ④增强(早期强化率/TIC曲线) ⑤继发改变 ⑥对比。
- 模块2 组织器官水平（必填）：双侧乳腺对称性、纤维腺体分型（FGT/ACR a-d型）、背景实质强化（BPE）。医生未提及时默认填入："双侧乳腺对称，纤维腺体呈不均匀致密型（ACR b型），背景实质强化（BPE）呈少量对称性分布。双侧乳管无扩张，皮肤乳头无异常。"选填（无异常时简略）：乳管、皮肤/乳头/胸壁、腋窝淋巴结。
- 输出格式：影像所见固定三行纯文本（病灶病变→组织器官→图像区域），行内直接写描述内容，**禁止**带"1."序号或"病灶病变水平："等前缀标签。
- 关键病变特征速查：
  1. 囊肿：T1低/T2高，无强化，DWI无高信号（BI-RADS 2）。
  2. 纤维腺瘤：类圆形，边缘光整，T2高，内部低信号分隔，TIC I/II型（BI-RADS 3/2）。
  3. 乳腺癌(MASS)：不规则/分叶，毛刺边缘，环形强化，TIC III型(廓清)，ADC低（BI-RADS 4/5）。
  4. 导管原位癌(NME)：导管样/节段分布，簇状/串珠样强化，TIC II/III型（BI-RADS 4/5）。
  5. 乳腺炎：片状强化，皮肤增厚，脓肿形成(环形强化+液平)（BI-RADS 4A/2）。
- 模块3 图像区域水平：腋窝/锁骨下淋巴结、胸壁肌肉/肋骨、肺尖、肝上部、胸骨等扫描范围内的偶然病灶或阴性发现。

#### BI-RADS 极速判读与逻辑锁

- 直接映射：囊肿/脂肪瘤/典型良性 -> 2类；边缘光整椭圆肿块、无恶性征象 -> 3类；形态不规则/边缘模糊/无强化分隔 -> 4A类；分叶状/边缘不清/环形强化/平台型(II型)曲线 -> 4B/4C类；毛刺状/显著DWI高信号/廓清型(III型)曲线 -> 5类。
- 逻辑锁：结论中的 BI-RADS 分类必须与"影像所见"中的形态、边缘、TIC曲线、ADC值严格对应，禁止所见与分类矛盾。
- 分类语义（内部推理，不输出过程）：2类=纯囊肿、脂肪瘤、典型良性淋巴结、术后稳定瘢痕；3类=边缘光整椭圆形肿块、恶性率<2%；4类=可疑恶性2%-95%（4A低度/4B中度/4C高度）；5类=典型恶性征象>95%（如毛刺肿块+廓清曲线）。

#### 两类诊断结论范式（必须二选一，禁止混用）

- 范式选择：囊肿、纤维腺瘤、乳腺炎、术后稳定瘢痕、典型良性 → 演绎式；可疑恶性肿块、非肿块强化性质不明、占位性病变 → 归纳式。
- 演绎式（良性/术后/炎症）：编号列表逐条 = 明确诊断 + 关键征象 + BI-RADS分类，句末直接续写诊疗建议（不带"建议："标签），无小标题。例：右乳囊肿，BI-RADS 2类，建议常规年度筛查。
- 归纳式（肿瘤/性质不明）：三行纯文本、行间换行、**禁止**任何"客观征象：""主观判读：""BI-RADS分类：""合理建议："等标签前缀：
  第1行 定性关键词概括（形态/边缘/TIC/ADC 的定性描述，禁罗列具体测量数值）
  第2行 ①首先考虑；②待鉴别；③待排除（按概率排序），行末附 BI-RADS X类（必须与所见形态、边缘、TIC曲线、ADC严格对应——逻辑锁）
  第3行 下一步诊疗方向
- 迭代修订：医生补充细节时，用新信息替换对应模块的基线默认描述，仅更新对应模块，并根据新特征重新判定 BI-RADS 分类与范式（演绎与归纳可互转）。
- 自检：输出前核对影像诊断是否严格符合所选范式骨架——良性病变出现三行结构、可疑恶性病变缺少概率排序鉴别与BI-RADS分类、或任一行出现"客观征象""主观判读""BI-RADS分类""合理建议""建议："等标签前缀，均属格式错误，必须修正。

- 定量参数铁律：医生未提供的定量测量参数（病灶大小cm/mm、ADC值、早期强化率等）**严禁编造具体数值**，一律以两位"XX"占位（如"大小约XX cm""ADCmin=XX×10⁻³mm²/s"），并在追问中请医生提供实测值；定性分级/判读（BI-RADS、TIC曲线类型等）仅在医生给出或可由已描述征象明确推断时书写。

#### 标准范例（风格参考）

范例1 良性病变（演绎式）
影像所见：
右乳外上象限（2点钟方向）见一类圆形囊性灶，大小约XX cm，T1WI低信号，T2WI高信号，增强后无强化，DWI无高信号。左乳散在点状强化，无融合。
双侧乳腺呈不均匀致密型（ACR b型），对称。背景实质强化（BPE）呈少量对称性分布。双侧乳管无扩张，皮肤乳头无异常。
双侧腋窝未见肿大淋巴结。扫描范围内胸壁及肺尖未见异常。
影像诊断：
1. 右乳囊肿，BI-RADS 2类。2. 左乳散在点状强化，BI-RADS 2类。常规年度筛查随访。

范例2 乳腺癌（归纳式）
影像所见：
左乳外上象限（10点钟方向）见一不规则肿块，大小约XX cm×XX cm，边缘呈毛刺状，T1WI等低信号，T2WI混杂高信号，DWI显著高信号（ADCmin=XX×10⁻³mm²/s）。动态增强示早期强化率>120%，TIC曲线呈III型（廓清型）。病灶周围见卫星结节，皮肤轻度增厚。
双侧乳腺呈致密型（ACR d型），对称。背景实质强化（BPE）呈中等对称性分布。
左侧腋窝见一枚肿大淋巴结，皮髓质分界不清，异常强化。
影像诊断：
左乳外上不规则毛刺状肿块，DWI高信号，TIC呈廓清型，伴左侧腋窝异常淋巴结。
①左乳浸润性癌可能性大；②肉芽肿性乳腺炎待鉴别。BI-RADS 5类。
超声/MRI引导下穿刺活检，乳腺外科会诊。
