# 颅脑MRI标准化报告模板（严格遵循《AI输入规则》整合优化完整版）

---

## 前置语法规范

### 一、专用符号释义

| 符号 | 释义 |
|------|------|
| `、` | 并列可选描述术语 |
| `\|\|` | 意群二选一（逻辑"或"） |
| `&&` | 意群叠加补充（逻辑"且"） |
| `[ ]` | 仅分类/注释提示，不写入正式报告文本 |
| `项目符号` | 选填内容 |
| `数字序号` | 必填核心要素 |
| `…` | 解剖节段/区域占位 |
| `n/m` | 序数填充 |
| `?` | 病灶测量数值 |
| `~` | 可删除修饰词（`~不`、`~其余`） |

### 二、报告三大强制描述模块

1. **病灶病变水平**：单发/多发局灶病灶，固定 6 要素（基本特征、解剖位置分布、几何特征、影像信号/强化、继发结构功能改变、新旧对比变化）
2. **组织器官水平**：全颅脑整体结构、弥漫性病变、正常解剖基线描述
3. **图像区域水平**：扫描野内鼻窦、眼眶、颅骨、颈部上段等无关脏器及偶然意外病灶

### 三、两类诊断结论范式

| 范式 | 格式 | 适用场景 |
|------|------|----------|
| **演绎式** | 明确诊断 + 关键征象 + 建议 | 陈旧性梗死、良性退变、出血后遗症、术后复查、影像典型无争议病变 |
| **归纳式** | 客观征象 + 1~3 个概率鉴别诊断 + 建议 | 颅内肿瘤、急性炎症、脱髓鞘、血管畸形、性质不明占位 |

### 四、解剖定位统一规范

> 所有病灶描述需精准定位：细化至脑叶-脑回、脑沟、灰质核团、皮层下 U 型纤维、皮层深部非边缘区、皮层下边缘区、室管膜下、胼胝体、深部白质等具体结构，严格区分灰质、白质、室管膜区域，保证解剖描述精准统一。

#### 2.1 颅脑退行性/缺血性病变

##### （1）脑白质高信号/脑白质缺血变性（改良 Fezekas 1 级）

| 要素 | 说明 |
|------|------|
| 基本特征 | 脑部小血管慢性供血不足，皮层下、深部白质点状脱髓鞘、胶质增生，轻度生理性/病理性退变，无明显脑结构损伤 |
| 解剖位置 | 左/右/双侧大脑额叶、顶叶、颞叶、枕叶、丘脑-基底节、半卵圆中心、桥脑，散在分布于皮层下 U 型纤维、皮层深部非边缘区、皮层下边缘区 |
| 几何特征 | 散在多发斑点状异常信号，无融合、无片状病灶 |
| 影像特征 | 呈长 T2、长 T1 信号，T2-FLAIR 高信号，DWI 等或低信号，增强无强化 |
| 继发改变 | 无占位效应、无脑实质萎缩效应 |
| 时间变化 | 慢性稳定，无急性进展、无弥散受限急性期改变 |

**标准描述句式**：

```
左/右/双侧大脑额叶、顶叶、颞叶、枕叶、丘脑-基底节、半卵圆中心、桥脑见散在多发斑点状异常信号，分布于皮层下U型纤维、皮层深部非边缘区、皮层下边缘区，呈长T2长T1信号，T2-FLAIR呈高信号，DWI等或低信号，增强扫描无强化；病灶无占位效应及脑萎缩改变，符合脑白质高信号（改良Fezekas 1级）。
```

##### （2）脑白质高信号/脑白质缺血变性（改良 Fezekas 2 级）

| 要素 | 说明 |
|------|------|
| 基本特征 | 脑小血管病进展性改变，白质脱髓鞘病灶增多，部分融合，伴随轻度脑结构退变 |
| 解剖位置 | 左/右/双侧大脑各脑叶、丘脑-基底节、半卵圆中心、桥脑，累及皮层下区域、侧脑室室管膜下、胼胝体区域 |
| 几何特征 | 散在多发斑点状、部分融合呈斑块状异常信号 |
| 影像特征 | 长 T2 长 T1 信号，T2-FLAIR 高信号，DWI 等或低信号，无异常强化 |
| 继发改变 | 伴轻度脑萎缩效应，无明显占位、无水肿 |
| 时间变化 | 慢性缓慢进展，无急性缺血、出血征象 |

**标准描述句式**：

```
左/右/双侧大脑额叶、顶叶、颞叶、枕叶、丘脑-基底节、半卵圆中心、桥脑见散在多发斑点、部分融合呈斑块状白质高信号，分布于皮层下U型纤维、皮层深部非边缘区、皮层下边缘区、侧脑室室管膜下、胼胝体区域，呈长T2长T1信号，T2-FLAIR呈高信号，DWI等或低信号，增强无强化；病灶无占位效应，伴轻度脑萎缩改变，符合脑白质高信号（改良Fezekas 2级）。
```

##### （3）脑白质高信号/脑白质缺血变性（改良 Fezekas 3 级）

| 要素 | 说明 |
|------|------|
| 基本特征 | 重度脑小血管病改变，广泛白质脱髓鞘、病灶大片融合，伴随明显脑退行性损伤 |
| 解剖位置 | 全脑广泛累及，涵盖各脑叶、深部核团、室管膜下、胼胝体、脑干上段区域 |
| 几何特征 | 多发斑点、斑块状、斑片状融合性异常信号 |
| 影像特征 | 广泛长 T2 长 T1 信号，T2-FLAIR 弥漫高信号，DWI 等低信号，无强化 |
| 继发改变 | 伴随明显脑萎缩效应，脑室、脑沟代偿性改变 |
| 时间变化 | 慢性持续性进展，无急性急性期病变征象 |

**标准描述句式**：

```
左/右/双侧大脑额叶、顶叶、颞叶、枕叶、丘脑-基底节、半卵圆中心、桥脑见多发斑点、斑块状及斑片状融合性白质高信号，广泛分布于皮层下、室管膜下、胼胝体区域，呈长T2长T1信号，T2-FLAIR弥漫高信号，DWI等或低信号，增强无强化；无占位效应，伴显著脑萎缩改变，符合重度脑白质高信号（改良Fezekas 3级）。
```

##### （4）急性/亚急性脑梗死

| 要素 | 说明 |
|------|------|
| 基本特征 | 颅内血管供血中断，脑组织缺血缺氧、水肿、坏死，急性期以细胞毒性水肿为核心改变 |
| 解剖位置 | 大脑皮层、基底节区、丘脑、脑干、小脑等单血管供血区 |
| 几何特征 | 扇形、楔形、片状病灶，贴合血管供血区分布，边界急性期模糊 |
| 影像特征 | 片状不均匀长 T2 长 T1 信号，边缘、内部可见短 T2 信号提示微量出血，DWI 呈等、低信号/轻度高信号；无异常强化或轻度片状强化 |
| 继发改变 | 局部脑实质萎缩、脑组织轻度肿胀、脑沟变浅，大面积病灶可伴轻微占位效应 |
| 时间变化 | 亚急性期水肿逐步吸收，后期可遗留软化灶、局限性脑萎缩 |

**标准描述句式**：

```
左侧/右侧XX脑区见片状不均匀长T2长T1异常信号，病灶边缘及内部可见短T2信号，提示局部微量出血，DWI呈等/低信号，无明显异常强化；局部脑实质轻度萎缩、脑组织轻微肿胀，脑沟变浅，无明显占位效应及中线移位，符合急性/亚急性脑梗死影像表现。
```

##### （5）陈旧性脑梗死/脑软化灶

| 要素 | 说明 |
|------|------|
| 基本特征 | 既往脑梗死、脑损伤修复后遗留胶质瘢痕、囊变软化，为稳定性后遗症病变 |
| 解剖位置 | 大脑半球、基底节、小脑、脑干既往缺血损伤区域 |
| 几何特征 | 斑点状、片状局限性病灶，边界清晰，无浸润性生长 |
| 影像特征 | DWI 点状、片状高信号，相应区域呈略长 T2 长 T1 信号，T2-FLAIR 呈不均匀高信号，增强无强化 |
| 继发改变 | 无急性水肿、无占位效应，部分病灶伴局部局限性脑萎缩 |
| 时间变化 | 病灶长期稳定，无急性进展、无新鲜出血缺血征象 |

**标准描述句式**：

```
左侧/右侧XX脑区见点状、片状异常信号灶，相应区域呈略长T2长T1信号，T2-FLAIR呈不均匀高信号，DWI可见点状、片状高信号，增强扫描无强化；病灶边界清晰，无占位效应及急性水肿，局部可伴轻度局限性脑萎缩，考虑陈旧性脑梗死、脑软化灶形成。
```

#### 2.2 颅内出血性病变（分期精准描述）

##### （1）硬膜外/硬膜下/蛛网膜下腔出血

| 要素 | 说明 |
|------|------|
| 基本特征 | 颅内腔隙外伤性/自发性出血，不同时期血肿信号具有特征性演变规律 |
| 解剖位置 | 硬膜外、硬膜下、大脑纵裂、外侧裂、各脑沟脑池 |
| 几何特征 | 硬膜外血肿呈紧贴颅骨梭形、不跨越颅缝；硬膜下血肿新月形、可跨颅缝；蛛网膜下腔出血脑沟脑池铸型改变 |
| 影像特征 | 急性期：短 T2、等/短 T1 信号；亚急性期：长 T2、短 T1 混杂信号；陈旧期：边缘短 T2 信号，提示含铁血黄素沉积；整体呈不均匀混杂信号 |
| 继发改变 | 可伴邻近颅骨骨折、皮下软组织肿胀，大量出血可致脑组织受压、中线移位 |
| 时间变化 | 急性期信号稳定，亚急性期逐步吸收，陈旧期遗留含铁血黄素沉积 |

**标准描述句式**：

```
颅内XX区域见异常出血信号，硬膜外呈梭形、未跨越颅缝/硬膜下呈新月形/蛛网膜下腔见脑沟脑池铸型改变，呈不均匀混杂信号；急性期表现为短T2、等/短T1信号/亚急性期表现为长T2、短T1混杂信号/陈旧期边缘见短T2含铁血黄素沉积信号；邻近可见颅骨骨折不连续及头皮皮下软组织肿胀，~伴轻度脑组织受压，符合XX期颅内出血表现。
```

##### （2）脑内血肿

| 要素 | 说明 |
|------|------|
| 基本特征 | 脑实质内团块状出血灶，伴周围血管源性水肿，具有明确分期信号特点 |
| 解剖位置 | 基底节区、丘脑、大脑半球、小脑、脑干 |
| 几何特征 | 团块状混杂信号灶，边界相对清晰，周围环绕水肿带 |
| 影像特征 | 急性期：短 T2、等/短 T1 信号；亚急性期：长 T2、短 T1 信号；陈旧期：边缘短 T2 含铁血黄素沉积信号；DWI 信号混杂 |
| 继发改变 | 周围脑实质肿胀，存在不同程度占位效应，可致脑沟变浅、脑室受压、中线移位 |
| 时间变化 | 随病程逐步吸收演变，信号分期特征典型 |

**标准描述句式**：

```
XX脑区见团块状混杂信号血肿灶，急性期呈短T2、等/短T1信号/亚急性期呈长T2、短T1信号/陈旧期边缘见短T2含铁血黄素沉积信号；周围脑实质肿胀，伴不同程度血管源性水肿及占位效应，局部脑沟变浅、~脑室受压、~中线结构轻度移位，符合XX期脑内血肿表现。
```

##### （3）海绵状血管瘤

| 要素 | 说明 |
|------|------|
| 基本特征 | 先天性脑血管畸形，薄壁血管团构成，易反复微量出血，良性稳定病变 |
| 解剖位置 | 大脑半球、脑干、小脑单发或多发分布 |
| 几何特征 | 类圆形结节灶，边界清晰，典型爆米花样混杂信号 |
| 影像特征 | T1WI、T2WI 混杂高低信号，周边完整含铁血黄素低信号环；SWI 序列显著低信号，轻度强化或无强化 |
| 继发改变 | 小型病灶无水肿、无占位；合并急性出血时伴局部水肿、轻微占位 |
| 时间变化 | 长期稳定，可反复微量出血，信号缓慢演变 |

**标准描述句式**：

```
XX脑区见类圆形结节灶，边界清晰，T1WI、T2WI呈典型爆米花样混杂信号，周边见环形含铁血黄素低信号环；SWI序列病灶显示清晰、呈显著低信号，增强扫描无明显强化；病灶无明显水肿及占位效应，考虑海绵状血管瘤。
```

#### 2.3 颅内肿瘤性病变

##### （1）胶质类肿瘤（通用模板）

| 要素 | 说明 |
|------|------|
| 基本特征 | 神经胶质源性浸润性肿瘤，边界模糊，高级别易出现坏死、囊变、出血及明显水肿占位 |
| 解剖位置 | 大脑半球白质区、丘脑、脑干、小脑 |
| 几何特征 | 病灶形态不规则，边缘不清晰，与正常脑组织分界不清 |
| 影像特征 | 内部不均匀长 T2 长 T1 信号，DWI 不均匀高、等信号；可混杂短 T2 短 T1 信号提示出血；增强呈轻度/中等/显著强化，强化形态为不规则片状、环形、花环状、结节状，中心坏死囊变区无强化，病灶强化部分最大径线 ?mm |
| 继发改变 | 病灶周围弥漫性水肿，存在明确占位效应，导致脑回变形、局部脑沟变浅、侧脑室受压、中线结构移位 |
| 时间变化 | 低级别缓慢进展，高级别进展迅速、易复发、侵袭性生长 |

**标准描述句式**：

```
XX脑区见形态不规则异常病灶，边缘模糊、与正常脑组织分界不清，内部呈不均匀长T2长T1信号，DWI呈不均匀高/等信号，&&内部混杂短T2短T1信号提示局部出血；增强扫描病灶呈轻/中/显著强化，强化形态为不规则片状/环形/花环状/结节状，中心见无强化坏死囊变区，强化病灶最大径约?mm；病灶周围见弥漫性水肿，伴明显占位效应，局部脑回变形、脑沟变浅、侧脑室受压、中线结构向对侧移位，符合胶质类肿瘤影像表现。
```

##### （2）炎性、脱髓鞘类多发异常信号（通用模板）

| 要素 | 说明 |
|------|------|
| 基本特征 | 颅内炎性浸润、自身免疫性脱髓鞘病变，多发散在病灶，无明显实性肿块侵袭性 |
| 解剖位置 | 大脑半球白质、脑室旁、脑干、小脑多区域散在分布 |
| 几何特征 | 多发不规则小病灶，边缘欠清晰，无大块实性团块 |
| 影像特征 | 形态不规则、边缘不清，内部不均匀长 T2 长 T1 信号，DWI 不均匀略高或等信号；增强可呈轻度/中等/显著不规则片状、环形、结节状强化，病灶强化部分最大径线 ?mm，可伴微小囊变坏死 |
| 继发改变 | 轻症无明显水肿占位，重症可伴轻度脑组织水肿、轻微占位效应 |
| 时间变化 | 急性期病灶活跃、可强化，缓解期病灶稳定、无强化 |

**标准描述句式**：

```
颅内XX区域见多发不规则异常信号灶，边缘欠清晰、与正常脑组织分界欠佳，内部呈不均匀长T2长T1信号，DWI呈不均匀略高/等信号；增强扫描病灶呈轻/中/显著不规则片状/环形/结节状强化，部分病灶见微小囊变坏死，强化病灶最大径约?mm；~病灶周围轻度水肿、无明显占位效应，~无中线移位，符合炎性/脱髓鞘性病变影像特点。
```

##### （3）脑转移瘤

| 要素 | 说明 |
|------|------|
| 基本特征 | 全身恶性肿瘤血行转移至颅内，多发多见，典型小病灶大水肿，进展迅速 |
| 解剖位置 | 大脑半球灰白质交界区为主，双侧散在分布 |
| 几何特征 | 多发类圆形结节、肿块灶，边界相对清晰，大小不等 |
| 影像特征 | 内部不均匀长 T2 长 T1 信号，DWI 不均匀高、等信号；增强结节/环形强化，强化部分最大径线 ?mm |
| 继发改变 | 病灶周围弥漫性水肿，占位效应明显，可致脑回变形、脑沟变浅、脑室受压、中线移位 |
| 时间变化 | 短期快速增多、增大，水肿进行性加重 |

#### 2.4 炎性、脱髓鞘及感染性病变

##### （1）病毒性脑炎

| 要素 | 说明 |


### 范式 2：归纳式结论

> 适用场景：急性病变、肿瘤、炎性、脱髓鞘、不明占位。
>
> 格式：**客观核心征象** + **1~3 个概率排序鉴别诊断** + **明确临床建议**

**模板 1：急性梗死/出血**

```
客观征象：XX脑区急性弥散受限/出血信号，伴水肿、轻度占位。
主观判读：①急性脑梗死/急性脑出血；②炎性病变待鉴别。
建议：神经内外科急诊就诊，完善血管及检验检查，尽早干预，短期复查MRI。
```

**模板 2：颅内占位**

```
客观征象：颅内单发/多发实性/囊实性占位，伴异常强化、水肿及占位效应。
主观判读：①转移瘤/胶质瘤可能性大；②炎性肉芽肿待鉴别。
建议：多学科会诊，完善全身筛查，必要时病理确诊。
```

**模板 3：多发脱髓鞘**

```
客观征象：颅内多发脑室旁脱髓鞘病灶，时空多发、新旧并存。
主观判读：①多发性硬化；②脑小血管病脱髓鞘改变待鉴别。
建议：神经内科完善免疫、脑脊液检查，规范治疗随访。
```

**模板 4：鞍区占位**

```
客观征象：鞍区囊实性钙化占位，压迫周围结构。
主观判读：①颅咽管瘤；②鞍区其他良性肿瘤待鉴别。
建议：神经外科及内分泌科会诊，评估手术及内分泌干预指征。
```

## 四、完整报告样例

### 样例 1：脑白质高信号（Fezekas 2 级）合并脑萎缩、鼻窦炎

**影像描述**：

1. **病灶病变水平**：双侧侧脑室旁、半卵圆中心、桥脑见散在多发斑点及部分融合斑块状白质高信号，分布于皮层下、室管膜下区域，呈长 T2 长 T1 信号，T2-FLAIR 高信号，DWI 等低信号，增强无强化；无占位效应，伴轻度脑萎缩改变；脑实质内未见急性梗死、出血、肿瘤及大片炎性病灶。
2. **组织器官水平**：双侧大脑半球、小脑、脑干结构对称，中线结构居中；脑沟轻度增宽加深，脑室系统轻度扩张，符合轻度脑萎缩改变；脑灰白质分界基本清晰，垂体稍萎缩，蝶鞍内见脑脊液填充。
3. **图像区域水平**：双侧上颌窦黏膜轻度增厚，提示炎性改变；眼眶、其余鼻窦、乳突、颅骨及头皮软组织未见明确异常。

**诊断结论（演绎式）**：

```
1. 脑白质高信号（改良Fezekas 2级）；2. 轻度弥漫性脑萎缩、空蝶鞍（老年性退变）；3. 双侧上颌窦炎。建议神经内科规范调控血压、血糖、血脂等脑血管病危险因素，耳鼻喉科对症处理鼻窦病变，1年复查颅脑MRI评估病情。
```

**影像描述**：

2. **组织器官水平**：双侧颅脑结构大致对称，中线结构轻度向左侧移位；脑灰白质分界基本清晰，其余脑实质基线信号大致正常。
3. **图像区域水平**：扫描范围内鼻窦、眼眶、乳突、颅骨未见明确异常继发病灶。

**诊断结论（归纳式）**：

```
客观征象：双侧大脑半球多发灰白质交界区结节状强化病灶，伴典型小病灶大水肿特点，占位效应阳性。
主观判读：①颅内多发转移瘤可能性极大；②多发胶质瘤病待鉴别。
合理建议：完善全身肿瘤筛查、肿瘤标志物检查，神经外科联合肿瘤科会诊，明确原发病灶并制定后续治疗方案。
```

## 五、颅脑高频病变标准化关键词速查表

| 病变类型 | 核心标准化描述词 | 特征特异性征象 |
|----------|-----------------|---------------|
| **Fezekas 1 级脑白质高信号** | 散在斑点、无融合、无占位、无萎缩 | FLAIR 高信号、DWI 等低信号、双侧对称分布 |
| **Fezekas 2 级脑白质高信号** | 斑点部分融合、斑块状、轻度脑萎缩 | 累及室管膜下、胼胝体，无急性弥散受限 |
| **Fezekas 3 级脑白质高信号** | 大片融合斑片、广泛分布、显著脑萎缩 | 全脑白质弥漫 FLAIR 高信号、慢性重度退变 |
| **急性/亚急性脑梗死** | 血管区片状病灶、可伴微量出血、脑实质萎缩 | 长 T1 长 T2 信号、DWI 等/低信号、无急性高亮弥散 |
| **陈旧性脑软化灶** | 斑点片状信号、胶质瘢痕、稳定无进展 | DWI 陈旧性高信号、FLAIR 不均匀高信号、无强化 |
| **各期颅内出血/血肿** | 分期信号典型、血肿占位、周围水肿 | 急性期短 T2、亚急性期长 T2 短 T1、陈旧期含铁血黄素环 |
| **胶质类肿瘤** | 形态不规则、边界模糊、浸润生长、坏死囊变 | 花环状/不规则强化、信号混杂、水肿占位明显 |
| **炎性/脱髓鞘病变** | 多发散在、边界欠清、轻度强化、无实性肿块 | 无明显大水肿、无显著占位、病灶多发零散分布 |
| **颅内转移瘤** | 灰白质交界多发结节、小病灶大水肿、环形强化 | 双侧散在、大小不等、囊变多见、占位叠加 |
| **脑膜瘤** | 宽基底硬膜附着、边界清、脑回受压、无水肿 | 硬膜尾征、均匀显著强化、邻近蛛网膜下腔增宽 |
