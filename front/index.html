多轮对话

第一次请求省略 conversation_id，保存服务端首先返回的 ID：

{"type":"conversation","conversation_id":"conv_xxx"}

之后复用同一 ID：

{"message":"把右侧病灶描述得详细一点","conversation_id":"conv_xxx"}
后续请求复用相同 conversation_id 即可保持上下文。

Public SSE Contract

conversation · status · message · report · ambiguous · error · done · [DONE]

data: {"type":"conversation","conversation_id":"conv_xxx"}

data: {"type":"status","stage":"retrieving","message":"正在检索知识库"}

data: {"type":"report","content":"...","data":{"results":[]}}

data: {"type":"done","conversation_id":"conv_xxx"}

data: [DONE]
