# 胸椎MRI标准化报告模板（严格遵循《AI输入规则》扩充修订版）

---

## 前置语法规范

### 一、专用符号释义

| 符号 | 释义 |
|------|------|
| `、` | 并列可选描述术语 |
| `\|\|` | 意群二选一（逻辑"或"） |
| `&&` | 意群叠加补充（逻辑"且"） |
| `[ ]` | 仅分类/注释提示，不写入正式报告文本 |
| `项目符号` | 选填内容 |
| `数字序号` | 必填核心要素 |
| `…` | 解剖节段占位 |
| `n/m` | 序数填充 |
| `?` | 病灶测量数值 |
| `~` | 可删除修饰词（`~不`、`~其余`） |

### 二、报告三大强制描述模块

1. **病灶病变水平**：单发/同类多发局灶病灶，固定 6 要素（基本特征、解剖位置分布、几何特征、影像信号/强化、继发结构功能改变、新旧对比变化）
2. **组织器官水平**：全胸椎弥漫退行性改变、整体序列曲度、全段正常结构基线描述
3. **图像区域水平**：扫描野内无关脏器、偶然意外病灶

### 三、两类诊断结论范式

| 范式 | 格式 | 适用场景 |
|------|------|----------|
| **演绎式** | 明确诊断 + 关键征象 + 建议 | 退变、骨折、典型良性病灶、术后复查、已有临床/病理确诊病例 |
| **归纳式** | 客观征象 + 1~3 个概率鉴别诊断 + 建议 | 肿瘤、性质不明占位、炎性病变、血管畸形、定性困难病变 |

## 二、影像描述完整模块

### 模块 1：组织器官水平

> 全胸椎整体、弥漫退变、正常基线。

#### 1. 胸椎序列与生理曲度（必填）

```
胸椎序列规整，生理曲度正常 [无退变]。
|| 胸椎序列规整，生理曲度向后过度弧形突出、轻度侧弯 [退行性改变/脊柱侧弯]。
|| 胸椎序列不规整，多节段椎体旋转、楔形畸形 [结构性侧弯/发育畸形]。
```

#### 2. 全胸椎椎体基线通用描述（选填）

```
~其余胸n-m椎体骨质形态完整，骨髓信号均匀；椎弓根、椎板、横突、棘突等附件结构连续，无异常信号、骨质破坏、畸形改变。
```

#### 3. 全段椎间盘基线通用描述（选填）

```
~其余各节段胸椎椎间盘T2信号均匀，椎间隙高度正常，无脱水变性、膨出/突出，无后纵韧带增厚，未压迫硬膜囊、胸髓。
```

#### 4. 椎管、胸髓基线通用描述（选填）

```
~其余节段胸椎椎管前后径正常，硬膜囊形态规整；胸髓全程形态、信号均匀，髓内无异常信号，中央管无扩张、无萎缩；蛛网膜下腔间隙通畅。
```

#### 5. 韧带、椎旁软组织基线通用描述（选填）

```
~其余节段黄韧带、后纵韧带厚度正常，无肥厚骨化；棘间韧带、椎小关节囊、椎旁肌群信号均匀，无水肿、肿块、异常渗出。
```

#### 6. 附属脏器基线（选填）

```
扫描范围内胸廓入口、上段腰椎、纵隔周边结构、胸壁软组织未见明确异常占位、骨质破坏。
```

### 模块 2：病灶病变水平

> 局灶病灶，统一遵循 6 要素书写规范。

#### 2.1 胸椎退行性病变

##### （1）椎体骨质增生、楔形变、终板炎、许莫氏结节

```
胸m-n椎体前缘/侧缘骨质增生、骨赘突出、骨桥形成，合并椎小关节增生肥厚 [重度骨质增生]
|| 胸m-n椎体边缘轻度骨质增生，无椎管、胸髓压迫 [轻度骨质增生]。
胸m-n椎体轻度楔形改变，椎体高度轻度减低，为退行性形变改变。
胸m-n椎体终板信号模糊不连续，终板下骨质信号不均匀，伴骨髓水肿（Modic I型）|| 脂肪化（Modic II型）|| 骨质硬化（Modic III型）[终板炎]。
胸n椎体终板局限性缺损，形成Schmorl结节，~不伴周围骨髓水肿及椎体塌陷 [单纯许莫氏结节]。
```

##### （2）椎间盘脱水、膨出/突出、椎间隙狭窄

```
胸m-n椎间隙狭窄；椎间盘T2信号不均匀、脱水变性，向后突出，压迫硬膜囊&&胸髓受压，局部蛛网膜下腔变窄 [重度椎间盘病变]。
胸m-n椎间盘T2信号不均匀，提示轻度脱水变性，未见明显膨出、突出及压迫征象 [轻度椎间盘退变]。
```

##### （3）椎管狭窄、脊髓受压缺血改变

```
胸m-n节段椎管狭窄，由椎体骨质增生、椎小关节增生、黄韧带/后纵韧带增厚所致；硬膜囊、胸髓受压，髓内见小片絮状长T1、长T2缺血信号，中央管未见扩张，局部胸髓轻度萎缩 [重度椎管狭窄伴脊髓缺血]。
胸m-n节段椎管轻度狭窄，硬膜囊轻微受压，~无胸髓受压及髓内异常信号 [轻度椎管狭窄]。
```

##### （4）椎旁软组织炎性水肿

```
胸m-n棘突间韧带、椎小关节关节囊附着点、椎旁肌肉肌腱韧带附着点见絮状长T2水肿信号；肌间滑膜软组织见羽毛状长T2水肿信号 [软组织炎性水肿]。
肌肉肌腱韧带附着点以及肌间滑膜软组织无水肿、无异常信号 [正常软组织表现]。
```

#### 2.2 胸椎黄韧带肥厚/骨化

| 要素 | 说明 |
|------|------|
| 基本特征 | 胸椎退行性韧带增生肥厚、纤维化，部分进展为骨化，是胸椎管狭窄最常见诱因，多见于中下胸椎（T8-T12） |
| 解剖位置 | 胸n-n+1 节段椎管后壁、双侧椎板间黄韧带，可单侧/双侧对称受累 |
| 几何特征 | 黄韧带厚度 > 5mm，矢状位呈条索状、结节状向椎管内隆起；轴位呈半圆形/三角形凸起，多节段病变呈串珠样改变；硬膜外脂肪移位、连续性中断 |
| 影像特征 | 未骨化肥厚韧带 T1WI 中等信号、T2WI 稍高信号；完全骨化黄韧带 T1WI、T2WI 均呈极低信号；STIR 序列无高信号水肿，增强无强化 |
| 继发改变 | 肥厚骨化韧带压迫硬膜囊、胸髓，重度受压胸髓呈"蜂腰状"切迹、串珠样狭窄，髓内可出现长 T2 缺血水肿信号，严重者伴脊髓萎缩 |
| 时间变化 | 慢性退行性改变，随病程进展肥厚、骨化程度逐渐加重，脊髓压迫进行性加剧 |

**标准描述句式**：

```
胸n-n+1节段双侧黄韧带增厚（厚度约?mm），局部向椎管内结节状隆起，硬膜外脂肪间隙中断；肥厚韧带T1WI中等信号、T2WI稍高信号，部分区域见极低信号骨化灶；局部椎管继发性狭窄，硬膜囊受压，胸髓前缘见切迹样受压改变，髓内见絮状长T2缺血信号，~无脊髓明显萎缩。
```

#### 2.3 胸椎椎体血管瘤

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体内良性血管源性肿瘤，由增生血管、脂肪组织、增粗垂直骨小梁构成，生长缓慢，极少侵袭性改变 |
| 解剖位置 | 胸n椎体前部/中部，局限于椎体内，少数可累及椎弓根等附件 |
| 几何特征 | 单发/多发类圆形病灶，边界清晰规整；典型矢状位栅栏状、轴位圆点征改变，无骨质破坏、无浸润性边缘 |
| 影像特征 | 富脂型 T1WI 高信号、T2WI 显著高信号（灯泡征），STIR 序列持续高信号；乏脂型 T1WI 等/低信号、T2WI 高信号；增强后均匀轻中度强化 |
| 继发改变 | 普通型~无椎体塌陷、椎旁肿块、椎管压迫；侵袭性血管瘤可致椎体膨大、骨皮质变薄、椎旁软组织肿块，压迫胸髓 |
| 时间变化 | 病灶长期稳定，无明显进展，少数侵袭性病灶可缓慢增大 |

**标准描述句式**：

```
胸n椎体内见类圆形病灶，大小约?cm×?cm，边界清晰；T1WI高信号、T2WI显著高信号，内部见垂直走行增粗骨小梁低信号分隔（栅栏征），轴位可见圆点征，STIR序列信号无衰减；增强扫描病灶均匀轻度强化；病灶局限于椎体内，骨皮质完整，~无椎体压缩、椎旁软组织肿块、椎管狭窄及胸髓受压。
```

#### 2.4 胸椎椎体压缩骨折（新鲜良性/恶性病理性）

##### （1）新鲜良性骨质疏松性压缩骨折

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体骨皮质连续性中断、椎体楔形变，急性期伴广泛骨髓水肿，多为骨质疏松所致 |
| 解剖位置 | 胸n椎体前柱/前中柱，好发于中下胸椎 |
| 几何特征 | 椎体前部楔形塌陷，高度减低约 ?/m；椎体内见线状低信号骨折线，骨皮质皱褶，无虫蚀样破坏 |
| 影像特征 | T1WI 骨折区域弥漫低信号；T2WI、STIR 序列大范围高信号骨髓水肿；增强骨折区片状轻度强化；附件信号完整无异常 |
| 继发改变 | 椎旁局限性软组织水肿，边界规整，无实性肿块；重度塌陷可致椎管狭窄、硬膜囊轻微受压，~无胸髓明显受压坏死 |
| 时间变化 | 急性期水肿信号显著，恢复期水肿逐渐消退，陈旧性骨折骨髓信号恢复正常、残留椎体楔变畸形 |

**标准描述句式**：

```
胸n椎体前部楔形变，椎体高度减低约?/m；椎体内见线状低信号骨折线，T1WI椎体骨髓弥漫低信号，T2WI、STIR序列大范围高信号水肿；增强扫描骨折区域轻度片状强化；椎体骨皮质连续、无虫蚀样破坏，椎旁见局限性水肿信号，无实性软组织肿块，双侧椎弓根信号正常，~无胸髓明显受压。
```

##### （2）恶性病理性压缩骨折（转移瘤继发）

| 要素 | 说明 |
|------|------|
| 基本特征 | 肿瘤浸润破坏椎体骨质，继发椎体塌陷，为恶性病变所致病理性骨折 |
| 解剖位置 | 单发/多节段跳跃式胸椎椎体，常同步累及椎弓根、附件 |
| 几何特征 | 椎体不规则塌陷，骨皮质虫蚀样中断、缺损，边界模糊，无规整骨折线 |
| 影像特征 | T1WI 正常骨髓信号完全替代呈弥漫低信号；T2WI、STIR 混杂高信号；增强不均匀重度强化 |
| 继发改变 | 伴不规则椎旁、硬膜外软组织肿块，突入椎管压迫胸髓，椎间隙、终板结构多保留 |
| 时间变化 | 病灶进展迅速，短时间内椎体塌陷加重，新增受累椎体 |

**标准描述句式**：

```
胸n椎体不规则塌陷、楔形变，椎体及双侧椎弓根正常骨髓信号消失，骨皮质虫蚀样中断缺损；T1WI弥漫低信号，T2WI、STIR序列混杂高信号，增强扫描病灶不均匀重度强化；椎体后方见不规则软组织肿块突入椎管，硬膜囊、胸髓受压移位，椎间隙高度及终板结构基本保留。
```

#### 2.5 胸椎椎体转移瘤（溶骨/成骨/混合型）

| 要素 | 说明 |
|------|------|
| 基本特征 | 恶性肿瘤经血行/淋巴转移至胸椎，造成骨髓浸润、骨质破坏，多为多发跳跃性病灶 |
| 解剖位置 | 多节段胸椎椎体跳跃式分布，特征性优先累及椎体及椎弓根附件，可跨多胸段分布 |
| 几何特征 | 不规则片状、团块状病灶，边界模糊、浸润性生长；溶骨型见骨质缺损，成骨型见骨质致密硬化，混合型兼具两种改变 |
| 影像特征 | 溶骨型 T1WI 低信号、T2WI/STIR 高信号；成骨型 T1WI、T2WI 均低信号；混合型信号混杂；增强后不均匀中重度强化，坏死区无强化 |
| 继发改变 | 常伴椎旁、硬膜外软组织肿块，突入椎管致椎管狭窄、胸髓受压水肿；椎间隙多正常，无椎间隙狭窄（鉴别脊柱结核） |
| 时间变化 | 病灶进行性增大、增多，可继发多椎体病理性压缩骨折 |

**标准描述句式**：

```
胸n、胸m多节段椎体及双侧椎弓根正常骨髓信号消失，代之以不规则浸润性异常病灶；T1WI弥漫低信号，T2WI、STIR序列混杂高信号，增强扫描病灶不均匀重度强化，内部见无强化坏死区；局部骨皮质中断、骨质缺损，伴椎旁及硬膜外不规则软组织肿块，突入椎管压迫硬膜囊及胸髓，各受累节段椎间隙高度正常、终板无侵蚀破坏。
```

#### 2.6 胸椎管内神经源性肿瘤（神经鞘瘤/神经纤维瘤，髓外硬膜下）

| 要素 | 说明 |
|------|------|
| 基本特征 | 髓外硬膜下良性神经源性占位，神经鞘瘤多见，易囊变，典型哑铃状跨椎间孔生长，生长缓慢 |
| 解剖位置 | 胸n-n+1 椎管内髓外硬膜下，单侧椎间孔受累，椎管内外交通生长 |
| 几何特征 | 单发纺锤形、椭圆形或哑铃形，大小约 ?cm×?cm，边界光滑锐利；同侧椎间孔扩大，椎体后缘弧形压迹，无骨质侵蚀破坏 |
| 影像特征 | T1WI 等/稍低信号，T2WI 显著均匀高信号；内部常见囊变无强化区；实性部分增强后明显不均匀强化，囊壁环形强化 |
| 继发改变 | 硬膜囊、胸髓向对侧移位、受压变形；同侧神经根受压包绕，无脊髓浸润性破坏 |
| 时间变化 | 病灶缓慢增大，囊变区域可逐步扩大，长期随访无恶变进展 |

**标准描述句式**：

```
胸n-n+1水平椎管髓外硬膜下见纺锤形占位，大小约?cm×?cm，边界清晰光滑；病灶经单侧椎间孔向外延伸呈哑铃状，同侧椎间孔扩大，对应椎体后缘见弧形压迹，骨质完整无破坏；T1WI等信号，T2WI显著高信号，内部见小片囊变无强化区；增强扫描实性部分明显不均匀强化，囊壁环形强化；硬膜囊、胸髓向对侧移位受压，同侧神经根受压包绕。
```

#### 2.7 胸椎管内脑膜瘤（髓外硬膜下）

| 要素 | 说明 |
|------|------|
| 基本特征 | 胸段椎管内蛛网膜来源良性肿瘤，实性为主、囊变极少见，基底宽、附着硬脊膜，生长缓慢 |
| 解剖位置 | 中下段胸椎管髓外硬膜下，多附着于椎管侧后方/后方硬脊膜，极少跨椎间孔生长 |
| 几何特征 | 椭圆形、分叶状实性肿块，宽基底贴合硬脊膜，大小约 ?cm×?cm，边界清晰；可伴瘤内点状钙化低信号，无椎间孔扩大 |
| 影像特征 | T1WI 与胸髓等信号，T2WI 等/轻度高信号；增强后均匀中度强化，特征性出现肿瘤两端硬脊膜增厚强化（硬膜尾征），可见银杏叶征 |
| 继发改变 | 胸髓受压移位、蛛网膜下腔局部闭塞，仅压迫椎体骨质形成弧形压迹，无溶骨性、侵蚀性骨质破坏 |
| 时间变化 | 病灶生长极其缓慢，长期随访体积轻微增大，无侵袭性改变 |

**标准描述句式**：

```
胸n-n+1椎管内髓外硬膜下见椭圆形实性占位，宽基底附着于后方硬脊膜，大小约?cm×?cm，边界光滑规整；T1WI与胸髓信号均等，T2WI轻度高信号，内部见点状钙化低信号；增强扫描病灶均匀中度强化，肿瘤上下方硬脊膜增厚强化（硬膜尾征）；胸髓向前方受压移位，蛛网膜下腔局部狭窄，双侧椎间孔无扩大、无跨孔生长，椎体骨质无侵蚀破坏。
```

#### 2.8 胸段脊髓胶质瘤（髓内肿瘤）

##### （1）胸髓室管膜瘤（中央型、边界清晰）

| 要素 | 说明 |
|------|------|
| 基本特征 | 胸髓中央管起源髓内富血管肿瘤，边界相对清晰，易出血、囊变，特征性含铁血黄素帽征 |
| 解剖位置 | 胸髓中心区域，纵向累及 2~4 个胸椎节段，居中生长 |
| 几何特征 | 长条腊肠状、分叶团块状，受累节段胸髓均匀膨大，椎管轻度扩张，肿瘤两端常伴脊髓空洞 |
| 影像特征 | T1WI 等/低信号，内部出血灶呈局灶高信号；T2WI 混杂高信号；肿瘤头尾两端见薄层 T2 低信号含铁血黄素沉积（帽征）；增强不均匀显著强化 |
| 继发改变 | 胸髓膨大、蛛网膜下腔狭窄闭塞；高级别病灶可伴软脊膜播散，长期压迫椎体后缘形成弧形压迹 |
| 时间变化 | 进展缓慢，病程较长，晚期可出现椎管内播散 |

**标准描述句式**：

```
胸n-m节段胸髓中央见长条分叶状占位，纵向累及多个椎体节段，局部胸髓均匀膨大、椎管轻度扩张；T1WI主体等信号，内部见斑点状出血高信号；T2WI混杂高信号，肿瘤头尾两端见薄层低信号含铁血黄素沉积（帽征）；增强扫描病灶不均匀显著强化；肿瘤上下方伴脊髓空洞形成，蛛网膜下腔受压狭窄。
```

##### （2）胸髓星形细胞瘤（偏心浸润型、边界模糊）

| 要素 | 说明 |
|------|------|
| 基本特征 | 胸髓偏心性浸润性髓内肿瘤，低级别多见，边界模糊，无明确包膜，出血少见 |
| 解剖位置 | 胸髓单侧偏心分布，纵向多节段浸润生长，无居中局限特点 |
| 几何特征 | 胸髓不规则膨大，病灶与正常脊髓移行模糊、无清晰分界，无典型含铁血黄素帽征，空洞多位于肿瘤远端 |
| 影像特征 | T1WI 不均匀低信号，T2WI 弥漫高信号；低级别病灶轻度片状强化，高级别病灶不均匀团块状强化、伴坏死囊变 |
| 继发改变 | 广泛脊髓水肿，蛛网膜下腔全程受压变窄，晚期可出现软膜播散、脊髓萎缩 |
| 时间变化 | 低级别进展缓慢，高级别病灶进展迅速、短期增大 |

**标准描述句式**：

```
胸n-m节段胸髓偏心性不规则膨大，髓内见弥漫异常信号，病灶与正常脊髓边界模糊不清；T1WI不均匀低信号，T2WI广泛混杂高信号；增强扫描病灶内见散在片状轻度强化，远端伴局限性脊髓空洞；无明显瘤内出血、无含铁血黄素帽征，蛛网膜下腔全程受压变窄。
```

#### 2.9 脊髓脱髓鞘类病变（多发性硬化 MS / 视神经脊髓炎 NMO）

| 要素 | MS | NMO |
|------|-----|-----|
| 基本特征 | 自身免疫性炎性髓鞘脱失，短节段多灶型 | 自身免疫性炎性髓鞘脱失，长节段横贯型 |
| 解剖位置 | 胸髓外周白质、短节段、偏侧分布 | 胸髓中央灰质受累为主、长节段横贯全层 |
| 几何特征 | 单灶长度 < 2 个椎体高度，类圆形、斑片状，多发散在，仅累及脊髓半侧 | 单灶长度 ≥ 3 个椎体高度，横贯脊髓大部分横截面，单发病灶为主 |
| 影像特征 | T1WI 等/轻度低信号；T2WI 斑片状、条带状高信号；急性期增强细线样、条带状轻度强化，缓解期无强化；慢性期可遗留脊髓萎缩 | 同 MS 类似 |
| 继发改变 | 急性期胸髓轻度肿胀，无椎管扩张、无骨质压迫；慢性期脊髓变细、萎缩 | 同 MS 类似 |
| 时间变化 | 复发缓解型病灶新旧交替，急性期治疗后水肿、强化可完全消退，反复发作者遗留永久性脊髓萎缩 | 同 MS 类似 |

**MS 标准描述句式**：

```
胸n、胸m节段胸髓外周白质见多处短节段斑片状T2高信号病灶，单灶累及不足2个椎体高度，偏侧分布、未横贯脊髓；T1WI等信号，急性期增强呈细线样轻度强化；胸髓轻度肿胀，无囊变、出血、脊髓空洞及椎管扩张。
```

**NMO 标准描述句式**：

```
胸n-m节段胸髓见长节段横贯性T2混杂高信号炎性病灶，纵向累及多个椎体节段，以脊髓中央灰质受累为主；T1WI轻度低信号，增强扫描病灶内见散在条带状轻度强化；急性期胸髓均匀肿胀，无瘤样囊变、出血及含铁血黄素沉积。
```

#### 2.10 脊髓梗死

| 要素 | 说明 |
|------|------|
| 基本特征 | 脊髓血管供血中断所致缺血性坏死，急性起病，以脊髓灰质受累为主，典型"蛇眼征"为特异性表现 |
| 解剖位置 | 胸髓中下段多见（血管供血薄弱区），可累及单个或多个节段脊髓灰质、白质 |
| 几何特征 | 病灶沿脊髓纵轴分布，多为长节段，轴位呈双侧对称点状高信号（蛇眼征），无占位效应、无脊髓膨大 |
| 影像特征 | 急性期 T1WI 等/低信号，T2WI、STIR 双侧灰质对称高信号（蛇眼征）；亚急性期可出现轻度强化；慢性期病灶信号减低、脊髓萎缩 |
| 继发改变 | 急性期脊髓轻度水肿肿胀，无椎管狭窄、无骨质压迫；恢复期遗留脊髓萎缩、神经功能缺损 |
| 时间变化 | 急性期病灶信号典型、范围稳定，慢性期水肿消退，残留脊髓萎缩改变，无病灶进展增大 |

**标准描述句式**：

```
胸n-m节段胸髓内见长节段异常信号，轴位呈双侧灰质对称分布的点状T2高信号（蛇眼征）；T1WI等信号，STIR序列高信号清晰显示病灶范围；急性期脊髓轻度水肿肿胀，增强扫描无明显强化/轻度条带状强化；病灶无占位效应，无囊变、出血，椎管无扩张、无骨质压迫，慢性期局部胸髓轻度萎缩。
```

#### 2.11 脊髓 AVF 动静脉畸形

| 要素 | 说明 |
|------|------|
| 基本特征 | 脊髓先天性血管发育异常，动静脉直接交通，无正常毛细血管网，易淤血、出血、压迫脊髓 |
| 解剖位置 | 胸髓背侧硬膜下/髓内，多位于中下胸段，沿脊髓纵轴走行 |
| 几何特征 | 椎管内见多发迂曲、条索状、团块状流空血管影，无实性肿块边界，沿脊髓表面匍匐生长 |

**标准描述句式**：

```

```

### 模块 3：图像区域水平

> 扫描野内无关脏器、偶然病灶。

1. **上段腰椎、胸廓入口结构**：`扫描范围内上段腰椎椎体、椎间盘、椎管及软组织未见明确异常病变。`
2. **胸壁及纵隔周边**：`胸壁肌肉、皮下软组织层次清晰，无水肿、占位；纵隔周边结构未见异常肿块、渗出。`

4. **偶然病灶备注**：`扫描范围内未见其他明确异常占位、炎性病变及外伤性改变。`

## 三、诊断结论

### 范式 1：演绎式结论

> 适用场景：退变、骨折、典型良性病灶、术后复查。
>
> 格式：**明确诊断** + **关键征象** + **合理建议**

| # | 场景 | 模板 |
|---|------|------|
| 1 | 胸椎退行性变 | `胸n-m椎间盘突出，伴椎体骨质增生、黄韧带肥厚，继发性椎管狭窄、胸髓受压缺血。建议骨科门诊就诊，结合胸背部疼痛、肢体麻木症状，定期胸椎MRI随访。` |
| 2 | 新鲜压缩骨折 | `胸n椎体新鲜压缩性骨折，伴骨髓水肿、椎旁软组织水肿。建议骨科专科就诊，规范抗骨质疏松、制动治疗，1~3月复查胸椎MRI评估水肿吸收及骨折愈合情况。` |
| 3 | 椎体血管瘤 | `胸n椎体良性血管瘤，无椎管狭窄、胸髓受压征象。建议常规年度体检随访，出现胸背部疼痛、肢体麻木时骨科就诊。` |
| 4 | 黄韧带肥厚/骨化 | `胸n-n+1节段黄韧带肥厚、骨化，继发性轻度椎管狭窄，无明显胸髓受压。建议骨科对症保守治疗，定期复查评估病情进展。` |

---

### 范式 2：归纳式结论

> 适用场景：肿瘤、炎性病变、血管畸形、定性困难病灶。
>
> 格式：**客观核心征象** + **按概率排序 1~3 个鉴别诊断** + **明确临床建议**

**模板 1：椎管内神经源性肿瘤**

```
客观征象：胸n-n+1椎管内哑铃形髓外硬膜下占位，跨椎间孔生长、椎间孔扩大，病灶囊变、T2显著高信号。
主观判读：①胸段神经鞘瘤（良性）；②神经纤维瘤待鉴别。
建议：神经外科会诊，评估手术切除指征。
```

**模板 2：多发椎体转移**

```
客观征象：胸n-m多节段椎体及椎弓根骨质破坏性病灶，伴椎旁硬膜外软组织肿块、胸髓受压。
主观判读：①多发胸椎椎体转移瘤可能性大；②多发性骨髓瘤待鉴别。
建议：结合全身肿瘤病史、骨扫描、肿瘤标志物检查，肿瘤科+骨科联合会诊。
```

**模板 3：长节段脱髓鞘**

```
客观征象：胸n-m长节段胸髓横贯性T2高信号炎性病灶，急性期条带状强化。
主观判读：①视神经脊髓炎谱系疾病；②多发性硬化待鉴别。
建议：神经内科就诊，完善AQP4/MOG抗体、脑脊液检查，规范治疗后定期复查。
```

**模板 4：脊髓梗死**

```
客观征象：胸n-m胸髓内长节段对称性灰质高信号，可见蛇眼征，无占位效应。
主观判读：①脊髓梗死可能性大；②脊髓炎性病变待鉴别。
建议：神经内科、介入科联合会诊，完善血管检查，对症治疗。
```

**模板 5：脊髓 AVF**

```
客观征象：胸n-m椎管内多发迂曲流空血管影，伴胸髓淤血水肿。
主观判读：①脊髓动静脉畸形（AVF）；②脊髓血管曲张待鉴别。
建议：神经外科、介入科就诊，完善脊髓血管造影，明确病变分型并干预。
```

## 四、完整报告样例

### 样例 1：胸椎重度退行性变（演绎式结论）

**影像描述**：

1. **组织器官水平**：胸椎序列规整，生理曲度轻度后凸畸形；其余胸椎椎体、附件骨髓信号均匀，大部分节段椎间盘、椎管、胸髓基线信号未见异常。
2. **病灶病变水平**：胸9-10、胸10-11椎体边缘骨质增生、骨赘形成，椎小关节增生肥厚，对应节段黄韧带肥厚；胸10-11椎间盘脱水变性、向后突出，椎间隙狭窄；局部继发性椎管狭窄，硬膜囊、胸髓受压，髓内见絮状长T2缺血信号；局部椎体终板信号不连续，伴轻度终板炎；椎旁软组织轻度炎性水肿，无实性肿块。
3. **图像区域水平**：扫描范围内上段腰椎、胸壁软组织、肋骨近端未见明确异常偶然病灶。

**诊断结论（演绎式）**：

```
胸椎退行性变：胸9-10、10-11椎间盘突出、椎体骨质增生、黄韧带肥厚，继发性椎管狭窄，伴胸髓受压缺血、椎体终板炎。建议骨科专科就诊，结合临床症状对症治疗，6~12个月复查胸椎MRI评估病情。
```

### 样例 2：胸椎多发转移瘤（归纳式结论）

**影像描述**：

1. **组织器官水平**：胸椎序列规整，生理曲度尚可；多节段胸椎椎体骨髓信号异常，其余软组织、椎管基线结构大致正常。
2. **病灶病变水平**：胸6、胸8、胸10多节段椎体及双侧椎弓根骨髓正常信号消失，代之以不规则浸润性病灶；T1WI弥漫低信号，T2WI、STIR混杂高信号，增强扫描不均匀重度强化；胸8椎体骨皮质中断、轻度病理性塌陷，椎体后方见不规则硬膜外软组织肿块，突入椎管压迫硬膜囊及胸髓；各受累节段椎间隙高度正常，终板无侵蚀破坏。
3. **图像区域水平**：扫描范围内胸壁、上段腰椎未见明确转移及异常偶然病灶。

**诊断结论（归纳式）**：

```
客观征象：胸6、8、10多节段椎体及椎弓根骨质破坏性病灶，伴病理性椎体塌陷、硬膜外软组织肿块、胸髓受压。
主观判读：①多发胸椎椎体转移瘤可能性大；②多发性骨髓瘤待鉴别。
合理建议：结合全身肿瘤病史、全身骨扫描及肿瘤标志物检查，肿瘤科联合骨科会诊，进一步明确诊断并干预。
```
