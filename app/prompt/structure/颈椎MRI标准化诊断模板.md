# 颈椎MRI标准化诊断模板（AI报告规则重构版）

> 本模板严格遵循《AI报告的构成规则和要求》构建，包含三大描述模块（病灶病变水平→组织器官水平→图像区域水平）、病灶 6 项必填要素、两类诊断结论范式，并整合颈椎 MRI 专业分级标准与诊断规范。

---

## 一、前置语法规范

### 1.1 专用符号释义

| 符号 | 含义说明 |
|------|----------|
| `、` | 并列列举（可选描述术语之间的并列关系） |
| `\|\|` | 或（多选一，意群二选一的逻辑关系） |
| `&&` | 且（同时存在，意群叠加补充的逻辑关系） |
| `[ ]` | 可选内容/分类注释提示，不写入正式报告文本 |
| `…` | 省略/可扩展，解剖节段占位符 |
| `n/m` | 分数形式表达（如程度分级、椎体高度丢失比例） |
| `?` | 可疑/待确认，病灶测量数值占位符 |
| `~` | 大约/左右，或可删除修饰词（`~不`、`~其余`） |

### 1.2 报告三大强制描述模块（固定顺序，不可调换）

1. **病灶病变水平** —— 聚焦具体病变本身，单发/同类多发局灶病灶，固定 6 要素
2. **组织器官水平** —— 描述受累组织器官的整体状态，全颈椎弥漫退行性改变、整体序列曲度、全段正常结构基线描述
3. **图像区域水平** —— 描述扫描范围内的整体图像质量与范围，扫描野内无关脏器、偶然意外病灶

### 1.3 病灶病变水平的 6 项必填要素

| # | 要素 | 说明 |
|---|------|------|
| 1 | **基本特征** | 是什么病变（病变性质、组织来源） |
| 2 | **解剖位置分布** | 在哪里（具体节段、方位、层次） |
| 3 | **几何特征** | 大小/形态/数量 |
| 4 | **影像信号/密度表现** | T1WI、T2WI、STIR、增强等信号特征 |
| 5 | **继发结构功能改变** | 对周围组织的压迫、移位、水肿等 |
| 6 | **时间对比** | 如有既往对比，描述变化趋势 |

### 1.4 两类标准化诊断结论范式

| 范式类型 | 格式 | 适用场景 |
|----------|------|----------|
| **演绎式结论** | 明确诊断 + 关键征象 + 合理建议 | 退变、骨折、典型良性病灶、术后复查、已有临床/病理确诊病例 |
| **归纳式结论** | 客观核心征象 + 按概率排序 1~3 个鉴别诊断 + 明确临床建议 | 肿瘤、性质不明占位、炎性脱髓鞘、定性困难病变 |

## 二、基础扫描信息

```
检查内容：脊柱-颈椎-MRI-平扫 || 平扫+增强（肌肉骨关节系统）
扫描序列：矢状位T1WI、矢状位T2WI [mDIXON水脂分离]、横轴位T2WI、STIR/T2压脂序列 [&& 增强扫描：矢状位+横轴位T1WI增强]
扫描范围：颅底至T1/T2椎体水平
```

## 三、影像描述完整模块

> 模块顺序要求：必须按「**病灶病变水平 → 组织器官水平 → 图像区域水平**」的固定顺序书写，不可调换。病灶病变水平为核心重点，组织器官水平提供整体背景，图像区域水平收尾。

##### （2）颈椎椎体转移瘤（溶骨/成骨/混合型）

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体骨质破坏性恶性占位，骨髓广泛肿瘤浸润 |

| 影像信号 | T1WI 正常高信号骨髓完全替代呈弥漫低信号；T2WI 混杂高信号；STIR 大范围水肿高信号；增强不均匀中-重度强化；成骨性转移 T1/T2 均呈低信号 |
| 继发改变 | 椎旁软组织肿块突入椎管，硬膜囊、颈髓受压水肿；椎间隙、终板结构多保留（鉴别脊柱结核）；附件同步骨质破坏 |
| 时间对比 | 随访病灶范围扩大、新增受累椎体、椎体塌陷进展 |

**标准描述句式**：

```

```

| 继发改变 | 颈髓受压移位、蛛网膜下腔局部闭塞；仅压迫椎体骨质，无溶骨性破坏 |

**标准描述句式**：

```
颈C4-C5椎管内髓外硬膜下见椭圆形实性占位，宽基底附着于后方硬脊膜，大小约 ?cm×?cm，边界光滑；T1WI与颈髓等信号，T2WI轻度高信号，内部见点状钙化低信号；增强扫描病灶均匀中度强化，肿瘤上下方硬脊膜增厚强化（硬膜尾征）；颈髓向前方受压移位，双侧椎间孔无扩大、无跨孔生长。
```

##### （3）颈髓胶质瘤（髓内肿瘤）

**A. 颈髓室管膜瘤（中央型，边界清晰）**

| 要素 | 说明 |
|------|------|
| 基本特征 | 髓内中央起源富血管肿瘤，易出血、囊变，特征性头尾端含铁血黄素"帽征" |
| 解剖位置 | 颈髓中心管周围，纵向累及 2~4 个颈椎节段 |
| 几何特征 | 长条腊肠状、分叶团块；受累节段颈髓均匀膨大，椎管轻度扩张；肿瘤两端常伴脊髓空洞 |
| 影像信号 | T1WI 等/低信号，内部出血呈局灶高信号；T2WI 混杂高信号；肿瘤头尾两端薄层 T2 低信号（含铁血黄素帽征）；增强不均匀显著强化 |
| 继发改变 | 颈髓膨大、蛛网膜下腔变窄；高级别可伴软脊膜播散；长期压迫椎体后缘弧形压迹 |
| 时间对比 | 进展缓慢，可出现颅内椎管播散 |

**标准描述句式**：

```

```

**B. 颈髓星形细胞瘤（偏心浸润型，边界模糊）**

| 要素 | 说明 |
|------|------|
| 基本特征 | 髓内偏心浸润性肿瘤，低级别出血少见、高级别可见坏死囊变，边界模糊不清 |
| 解剖位置 | 颈髓单侧偏心分布，纵向多节段浸润生长 |

## 四、诊断结论

### 4.1 范式一：演绎式结论

> 适用场景：退变、骨折、典型良性病灶、术后复查。
>
> 格式：**明确诊断** + **关键征象** + **合理建议**

| # | 场景 | 模板 |
|---|------|------|
| 1 | 颈椎退行性变 | `颈椎退行性变：C4-5椎间盘突出（Pfirrmann IV级，旁中央型），伴椎体骨质增生、后纵韧带增厚、椎管狭窄（Kang 2级），颈髓受压。建议骨科门诊就诊，结合肢体麻木症状定期颈椎MRI随访。` |
| 2 | 新鲜压缩性骨折 | `C5椎体新鲜压缩性骨折：伴广泛骨髓水肿、椎旁软组织水肿。建议骨科专科就诊，规范抗骨质疏松治疗，1~3月复查颈椎MRI评估水肿吸收。` |
| 3 | 良性血管瘤 | `C3椎体良性血管瘤：无椎管、颈髓压迫征象。建议每年常规体检随访，出现颈痛、手麻时骨科就诊。` |
| 4 | OPLL | `颈椎后纵韧带骨化症（OPLL）：C3-6节段型，继发椎管狭窄（Kang 2级），颈髓受压。建议骨科/脊柱外科就诊，结合JOA评分评估手术指征。` |

---

### 4.2 范式二：归纳式结论

> 适用场景：肿瘤、脱髓鞘、性质不明病灶、恶性可疑。
>
> 格式：**客观核心征象** + **按概率排序 1~3 个鉴别诊断** + **明确临床建议**

**模板 1：椎管占位（神经鞘瘤）**

```
客观征象：C3-C4椎管内哑铃形髓外硬膜下占位，同侧椎间孔扩大，病灶囊变、T2显著高信号。
主观判读：①神经鞘瘤（良性）；②神经纤维瘤待鉴别。
建议：神经外科会诊，评估手术切除指征。
```

**模板 2：髓内占位（室管膜瘤）**

```
客观征象：C2-C5颈髓长条分叶状强化占位，伴头尾端含铁血黄素帽征、脊髓空洞。
主观判读：①颈髓室管膜瘤；②星形细胞瘤待鉴别。
建议：神经外科就诊，完善全脊髓MRI排查软脊膜播散。
```

**模板 3：脱髓鞘病变（NMO）**

```
客观征象：C2-C7颈髓长节段横贯性T2高信号炎性病灶，急性期条带状强化。
主观判读：①视神经脊髓炎谱系疾病；②多发性硬化待鉴别。
建议：神经内科就诊，完善AQP4/MOG抗体、脑脊液寡克隆带检查。
```

**模板 4：多节段骨质破坏（转移瘤）**

```
客观征象：C2、C4多节段颈椎体及椎弓根骨质破坏，伴椎旁软组织肿块、颈髓受压。
主观判读：①多发颈椎椎体转移瘤可能性大；②多发性骨髓瘤待鉴别。
建议：结合全身肿瘤病史、全身骨扫描、肿瘤标志物，肿瘤科+骨科联合会诊。
```

|------|-----------|-----------|----------|
| **I 型** | 低信号 | 高信号 | 水肿/炎症期，血管化纤维组织，与疼痛相关 |
| **II 型** | 高信号 | 等/高信号 | 脂肪期，黄骨髓转化，相对稳定 |
| **III 型** | 低信号 | 低信号 | 硬化期，骨质硬化，终末期退变 |

## 六、常见颈椎疾病诊断标准

### 6.1 颈椎病诊断标准

| 类型 | 诊断要点（临床 + 影像） |
|------|----------------------|
| **神经根型颈椎病** | ① 典型神经根性症状（上肢放射痛、麻木），与受累神经根支配区一致；② MRI 显示相应节段椎间盘突出/骨赘压迫神经根；③ 压颈试验/臂丛牵拉试验阳性；④ 排除其他病因 |
| **脊髓型颈椎病** | ① 脊髓受压症状（四肢麻木无力、步态不稳、踩棉花感、精细动作障碍）；② MRI 显示脊髓受压变形，~ 伴髓内 T2 高信号；③ 腱反射亢进、Hoffmann 征阳性、肌张力增高；④ mJOA 评分评估严重程度 |
| **交感型颈椎病** | ① 头晕、头痛、心慌、视物模糊等交感神经症状；② 颈椎退变征象，无明确脊髓/神经根压迫；③ 症状与颈部活动相关；④ 排除其他系统疾病 |
| **椎动脉型颈椎病** | ① 发作性眩晕、猝倒，与颈部旋转有关；② 椎动脉受压/狭窄征象（MRA/CTA 证实）；③ 颈椎退变伴钩椎关节增生；④ 排除耳源性、眼源性眩晕 |

### 6.2 颈椎间盘突出症诊断标准

1. 典型的颈肩痛/上肢放射痛，与神经根支配区一致
2. MRI 显示椎间盘突出（膨出/突出/脱出），压迫相应神经根或脊髓
3. 神经系统体征与受累节段相符（感觉、运动、反射改变）
4. 排除颈椎管狭窄、颈椎肿瘤、胸廓出口综合征等其他疾病

### 6.3 颈椎管狭窄症诊断标准

1. 渐进性四肢麻木无力、步态不稳等脊髓受压症状
2. MRI 显示椎管前后径减小（<12mm 为相对狭窄，<10mm 为绝对狭窄），硬膜囊、脊髓受压
3. 多节段退变（椎间盘突出、骨质增生、韧带肥厚）共同导致椎管狭窄
4. Kang 分级 ≥2 级提示有临床意义的狭窄

### 6.4 颈椎不稳诊断标准

1. 颈部疼痛、活动受限，可伴神经根/脊髓症状
2. 动力位 X 线：椎体滑移 > 3mm，或成角 > 11°
3. MRI 可显示椎间盘退变、椎间隙狭窄、终板信号异常
4. 排除创伤、感染、肿瘤等病理性不稳

## 七、完整报告样例

### 7.1 样例一：轻度颈椎退行性变（演绎式结论）

**检查项目**：`颈椎MRI平扫`

**【病灶病变水平】**

C5-6 椎体边缘轻度骨质增生；C5-6 椎间盘 Pfirrmann III 级退变，髓核脱水变性短 T2 信号，轻度膨出，硬膜囊轻微弧形受压，~无颈髓、神经根、椎动脉受压；C5-6 椎小关节轻度增生，黄韧带轻微增厚，椎管轻度狭窄（Kang 1 级），颈髓无明显受压；无椎体破坏、骨髓水肿、椎管内占位、椎旁软组织肿块。

**【组织器官水平】**

颅颈交界及寰枢关节对位正常，颈椎序列规整，生理曲度轻度变直；其余颈椎椎体、附件骨髓信号均匀，各节段椎间隙高度正常，颈髓、神经根、椎动脉基线未见异常。

**【图像区域水平】**

扫描范围内颅底、甲状腺、上段胸椎、颈肩部软组织未见偶然异常病灶。

**【诊断结论（演绎式）】**

```
颈椎轻度退行性变：C5-6椎间盘轻度膨出（Pfirrmann III级），伴椎体骨质增生、椎管轻度狭窄（Kang 1级）。建议骨科门诊对症处理，1年复查颈椎MRI。
```

---

### 7.2 样例二：C3-C4 椎管神经鞘瘤（归纳式结论）

**检查项目**：`颈椎MRI平扫+增强`

**【病灶病变水平】**

| 要素 | 内容 |
|------|------|
| ① 基本特征 | 椎管内髓外硬膜下占位，考虑神经源性肿瘤 |
| ② 解剖位置 | C3-C4 水平椎管内髓外硬膜下，经右侧椎间孔向外延伸 |
| ③ 几何特征 | 哑铃形占位，大小约 1.8cm×1.2cm，边界清晰；右侧椎间孔扩大，对应椎体后缘弧形压迹 |
| ④ 影像信号 | T1WI 等信号，T2WI 显著高信号，内部见小片囊变无强化区；增强实性部分明显不均匀强化 |
| ⑤ 继发改变 | 硬膜囊、颈髓向左侧移位，右侧神经根受压包绕；椎体骨皮质仅弧形压迹，无骨质破坏 |
| ⑥ 时间对比 | 无既往片对比 |

**【组织器官水平】**

颅颈交界对位正常，颈椎序列、生理曲度正常；全段椎体骨质、椎间盘、颈髓基线信号大致正常。

**【图像区域水平】**

甲状腺、上段胸椎、颅底未见异常病灶。

**【诊断结论（归纳式）】**

```
客观征象：C3-C4椎管髓外硬膜下哑铃形占位，跨右侧椎间孔生长，病灶囊变、T2明显高信号，椎间孔扩大。
主观判读：① 右侧C3-C4神经鞘瘤（良性）；② 神经纤维瘤待鉴别。
合理建议：神经外科会诊，评估手术切除指征。
```

---

### 7.3 样例三：脊髓型颈椎病伴 OPLL（演绎式结论）

**检查项目**：`颈椎MRI平扫`

**【病灶病变水平】**

C3-6 椎体后缘见条带状 T1WI/T2WI 低信号影，符合后纵韧带骨化（OPLL），分型为节段型，骨化灶最大厚度约 4mm；继发 C4-5 节段椎管狭窄（Kang 3 级），硬膜囊受压，脊髓受压变形（Nagata 2 级），髓内见片絮状 T2 高信号，提示脊髓水肿/软化。C4-5、C5-6 椎间盘 Pfirrmann IV 级退变，向后旁中央型突出，加重椎管狭窄。双侧椎间孔狭窄，双侧神经根受压。

**【组织器官水平】**

颅颈交界对位正常，颈椎序列规整，生理曲度变直；C3-6 椎体边缘骨质增生，椎小关节增生肥厚；其余节段椎体、椎间盘、脊髓未见明显异常。

**【图像区域水平】**

扫描范围内颅底、甲状腺、上段胸椎未见明显异常。

**【诊断结论（演绎式）】**

```
1. 颈椎后纵韧带骨化症（OPLL，节段型，C3-6），继发C4-5椎管重度狭窄（Kang 3级），颈髓受压伴髓内信号改变，符合脊髓型颈椎病表现。建议脊柱外科就诊，结合mJOA评分评估手术指征。
2. 颈椎退行性变（C4-5、C5-6椎间盘突出，椎体骨质增生）。
```

## 八、各类病变标准化关键词速查表

| 病变类型 | 核心标准化描述词 | 特征特异性征象 |
|----------|-----------------|---------------|
| **颈椎椎体血管瘤** | 类圆形、栅栏状骨小梁、脂肪基质、边界清晰、无骨质侵袭 | 栅栏征、圆点征、T1 高信号、STIR 持续高信号、均匀轻度强化 |
| **颈椎椎体转移瘤** | 多节段跳跃病灶、椎弓根受累、虫蚀样骨质破坏、椎旁软组织肿块 | T1 弥漫低信号、不均匀重度强化、椎间隙保留、附件同步破坏 |
| **颈椎新鲜压缩骨折** | 椎体楔变、线状骨折线、大范围骨髓水肿、局限性椎旁水肿 | STIR 大片高信号水肿带、椎体内积液征、附件信号完整、无实性肿块 |
| **颈椎管神经鞘瘤** | 哑铃形、跨椎间孔、髓外硬膜下、囊变多见 | T2 显著高信号、椎间孔扩大、实性部分明显不均匀强化 |
| **颈椎管脑膜瘤** | 宽基底硬脊膜附着、椭圆形、钙化多见、无跨孔生长 | 硬膜尾征、银杏叶征、均匀中度强化、T2 等脊髓信号 |
| **颈髓室管膜瘤** | 脊髓中央起源、腊肠状、多节段、两端空洞、出血帽征 | 含铁血黄素低信号帽、不均匀显著强化、边界相对清晰 |
| **颈髓星形细胞瘤** | 偏心浸润、边界模糊、多节段、远端空洞 | 无典型帽征、轻度片状强化、广泛脊髓水肿 |
| **颈髓脱髓鞘（MS）** | 短节段、外周白质、斑片状、多发散在 | <2 椎体高度、半脊髓受累、急性期细线样强化 |
| **颈髓脱髓鞘（NMO）** | 长节段横贯性、中央灰质受累、单发病灶 | ≥3 椎体高度、横贯大部分截面、急性期条带状强化 |
| **OPLL** | 后纵韧带骨化、椎管狭窄、脊髓压迫 | T1/T2 均低信号、Tsuyama 分型、CT 可见高密度骨化 |
| **椎间盘退变** | 脱水变性、信号减低、椎间隙狭窄 | Pfirrmann 分级、T2 信号减低、髓核-纤维环分界消失 |
| **椎间盘突出** | 膨出/突出/脱出、硬膜囊受压、神经根受压 | MSU 分型、中央/旁中央/椎间孔型、纤维环破裂 |
| **椎管狭窄** | 硬膜囊受压、脊髓变形、髓内信号改变 | Kang 分级 0-3 级、蛛网膜下腔闭塞、脊髓 T2 高信号 |

## 模板使用说明

1. 报告书写时严格遵循「**病灶病变水平 → 组织器官水平 → 图像区域水平**」三大模块顺序
2. 每个局灶病灶必须覆盖 6 项基本要素，缺一不可
3. 根据病变性质选择合适的诊断结论范式（演绎式/归纳式）
4. 分级标准（Pfirrmann、Kang、Nagata、MSU 等）用于量化评估，提高报告一致性
5. 专用符号（`||`、`&&`、`[ ]`、`?`、`~` 等）用于模板标记，正式报告中根据实际情况选用
