# 腰椎MRI标准化报告模板（权威分级扩充·填空式版）

> 本模板以《腰椎MRI标准化报告模板（严格遵循AI输入规则整理扩充版）》为蓝本，整合 NASS/ASNR/ASSR、ACR、中华医学会放射学分会等权威学会标准，涵盖 Pfirrmann 分级、MSU 分型、Lee 分级、Meyerding 分级、Modic 分型、Weishaupt 分级、Genant 分型等国际广泛认可的分级分类体系。
>
> 所有标准描述句式均以 `[ ]` 包裹，形成可直接填写的填空式模板。

---

## 前置说明

### 符号规范

| 符号 | 释义 |
|------|------|
| `、` | 并列可选描述词 |
| `\|\|` | 二选一（逻辑或） |
| `&&` | 叠加补充（逻辑且） |
| `[ ]` | 填空式模板：可直接替换/填充的标准描述句式 |
| `…` | 解剖节段占位 |
| `?` | 病灶测量数值 |
| `~` | 可删除修饰词（`~不`、`~其余`） |
| `n/m` | 序数填充 |
| `数字序号` | 必填描述模块 |
| `项目符号` | 选填补充征象 |

### 报告三大强制模块

1. **病灶病变水平**：单发/同类多发占位、骨质病灶，6 要素齐全（基本特征 + 解剖位置 + 形态学 + 影像学 + 继发改变 + 时间变化）
2. **组织器官水平**：全腰椎弥漫退变、整体序列曲度、正常结构基线
3. **图像区域水平**：扫描范围内其他脏器、偶然微小病灶

### 结论双范式

| 范式 | 适用场景 | 格式 |
|------|----------|------|
| **演绎式** | 退变/骨折/典型良性病灶/术后复查 | 明确诊断 + 关键征象 + 建议 |
| **归纳式** | 肿瘤/定性困难病灶 | 客观征象 + 1~3 个鉴别诊断 + 建议 |

#### 2.1 椎体退行性病变

##### （1）椎体骨质增生/楔变

```
[腰m-n椎体前缘/侧缘骨质增生、骨赘突出（重度骨质增生）]
|| [腰m-n椎体边缘轻度骨质增生，无椎管、椎间孔压迫（轻度骨质增生）]
[腰m-n椎体前部双凹、楔形变，椎体高度轻度减低（退行性楔变）]
```

##### （2）终板炎、许莫氏结节

**Modic 改变分型**：基于 T1WI 和 T2WI 信号改变，反映终板下骨髓的不同病理状态。

| 分型 | 病理类型 | MRI 信号特征 |
|------|----------|-------------|
| **Modic I 型** | 水肿/炎症型 | T1WI 低信号，T2WI 高信号（水肿样）；血管化纤维组织、炎症反应、终板裂隙 |
| **Modic II 型** | 脂肪型 | T1WI 高信号，T2WI 等或稍高信号；黄骨髓脂肪替代、慢性稳定期 |
| **Modic III 型** | 硬化型 | T1WI 和 T2WI 均为低信号；软骨下骨硬化、骨质增生 |

**终板受累程度**：轻度（< 25% 椎体高度）\|\| 中度（25%~50%）\|\| 重度（> 50%）

**标准描述句式**：

```
[腰m-n椎体上/下终板模糊，伴终板下骨髓水肿（Modic I型）|| 脂肪化（Modic II型）|| 骨质硬化（Modic III型），累及椎体高度约?%（轻/中/重度）]
[腰n椎体终板局限性缺损，形成Schmorl结节，~不伴周围骨髓水肿（单纯许莫氏结节）]
|| [腰n椎体终板许莫氏结节，周围伴片状水肿高信号（Modic I型改变）（活动性许莫氏结节）]
```

##### （3）椎间盘膨出/突出、椎间隙狭窄

> 多分级体系联合评估。

**Pfirrmann 椎间盘退变分级**：

| 分级 | 名称 | MRI 表现（T2WI 矢状位） |
|------|------|------------------------|
| **I 级** | 正常 | 均匀明亮高信号，椎间隙高度正常，髓核与纤维环分界清晰 |
| **II 级** | 早期退变 | 不均匀高信号，可有水平灰色带，髓核与纤维环分界清晰，椎间隙高度正常 |
| **III 级** | 中度退变 | 中等灰色信号，髓核与纤维环分界不清，椎间隙高度正常或轻度降低 |
| **IV 级** | 重度退变 | 低信号（黑色），髓核与纤维环分界消失，椎间隙高度中度降低 |
| **V 级** | 终末期 | 低信号（黑色），椎间隙塌陷/消失 |

**NASS/ASNR/ASSR v2.0 椎间盘命名标准**：

| 类型 | 定义与特征 |
|------|-----------|
| 椎间盘膨出（Bulge） | 弥漫性超出椎体边缘，范围 > 25% 周径，突出距离通常 < 3mm，纤维环完整 |
| 椎间盘突出（Protrusion） | 局灶性移位 ≤ 25% 周径，突出物最大径 < 基底部宽度（"颈宽头窄"），纤维环部分破裂 |
| 椎间盘脱出（Extrusion） | 突出物最大径 > 基底部宽度（"颈窄头宽"），纤维环完全破裂，仍与母体椎间盘相连 |
| 椎间盘游离（Sequestration） | 脱出髓核与母体椎间盘完全分离，可向上/下迁移，无连续性 |

**MSU 分型（大小 + 位置联合评估）**：

| 维度 | 分级 |
|------|------|
| 大小 | 1 级（未达小关节内线 50%）\| 2 级（超过 50%）\| 3 级（超出小关节内线） |
| 位置 | A 区（中央区）\| B 区（旁中央区）\| C 区（椎间孔区） |

**Lee 矢状位迁移分型**：

| 分区 | 范围 |
|------|------|
| I 区 | 上移 — 上位椎弓根下缘 3mm 以内 |
| II 区 | 上移 — 上位椎弓根下缘至椎体下缘 |
| III 区 | 下移 — 下位椎体上缘至椎弓根中线 |
| IV 区 | 下移 — 超过下位椎弓根中线 |

**标准描述句式（轻度）**：

```
[腰m-n椎间盘脱水变性短T2信号（Pfirrmann ?级），轻度膨出，硬膜囊弧形受压，~无椎间孔狭窄、神经根受压（轻度椎间盘病变）]
```

**标准描述句式（重度）**：

```
[腰m-n、腰5-骶1椎间隙狭窄；椎间盘髓核短T2信号（脱水变性，Pfirrmann ?级），向后膨出||突出||脱出（MSU ?级?区），压迫硬膜囊 && 左侧||右侧神经根脂肪间隙消失、神经根受压（重度椎间盘病变）]
```

**标准描述句式（脱出伴迁移）**：

```
[腰m-n椎间盘脱出（MSU ?级?区），髓核向上/下迁移至Lee ?区，大小约?mm×?mm，硬膜囊明显受压，左侧/右侧神经根受压变形]
```

##### （4）椎小关节、黄韧带、椎管狭窄

> 多分级体系联合评估。

**Weishaupt 小关节退变分级**：

| 分级 | MRI 表现 |
|------|---------|
| **0 级** | 正常：关节间隙正常（2~4mm），无骨赘，无关节突肥大，无软骨下侵蚀或囊肿 |
| **1 级** | 轻度：关节间隙狭窄（< 2mm）和/或轻度骨赘和/或轻度关节突肥大；无软骨下侵蚀或囊肿 |
| **2 级** | 中度：关节间隙狭窄，中度骨赘，中度关节突肥大，和/或轻度软骨下骨侵蚀 |
| **3 级** | 重度：关节间隙狭窄伴消失，重度骨赘，重度关节突肥大，软骨下侵蚀和/或软骨下囊肿形成 |

**Lee 中央管狭窄分级**：

| 分级 | 程度 | MRI 表现 |
|------|------|---------|
| **0 级** | 无狭窄 | 前部 CSF 空间完整，马尾神经根清晰分散 |
| **1 级** | 轻度狭窄 | 前部 CSF 空间轻度闭塞，马尾神经仍可分辨 |
| **2 级** | 中度狭窄 | 前部 CSF 空间中度闭塞，部分马尾神经聚集 |
| **3 级** | 重度狭窄 | 前部 CSF 空间严重闭塞，所有马尾神经聚集成束状 |

**Lee 椎间孔狭窄分级**：

| 分级 | 程度 | MRI 表现 |
|------|------|---------|
| **0 级** | 无狭窄 | 椎间孔形态正常，神经根周围脂肪间隙完整环绕 |
| **1 级** | 轻度狭窄 | 神经根周围脂肪在两个相对方向闭塞，神经根形态正常 |
| **2 级** | 中度狭窄 | 神经根周围脂肪在四个方向均闭塞，神经根形态无改变 |
| **3 级** | 重度狭窄 | 神经根形态改变（塌陷、变细或肿胀），或神经根被淹没 |

**黄韧带肥厚**：正常 < 4mm，轻度 4~5mm，中度 5~7mm，重度 > 7mm

**标准描述句式（轻度）**：

```
[腰m-n椎小关节轻度增生（Weishaupt ?级），黄韧带轻微增厚（厚度约?mm），椎管轻度狭窄（Lee ?级），硬膜囊轻度受压，~马尾、神经根无直接压迫（轻度椎管狭窄）]
```

**标准描述句式（重度）**：

```
[腰m-n椎小关节间隙不规则，关节突骨质增生肥厚呈蘑菇状（Weishaupt ?级），黄韧带增厚（厚度约?mm）；继发同节段椎管狭窄（Lee ?级），硬膜囊、马尾神经聚集受压 && 神经根卡压（重度椎管狭窄）]
```

#### 2.2 腰椎滑脱

> 分级与分类体系：Meyerding 分级（滑脱程度 I~V 度）、Wiltse-Newman 分类（滑脱病因 I~VI 型）。

**Meyerding 滑脱程度分级**：

| 分级 | 滑移程度 | 临床意义 |
|------|----------|----------|
| **I 度** | 滑移 < 25% | 轻度滑脱，多无症状或症状轻微 |
| **II 度** | 滑移 25%~49% | 中度滑脱，常伴腰痛和神经症状 |
| **III 度** | 滑移 50%~74% | 重度滑脱，明显神经功能障碍风险 |
| **IV 度** | 滑移 75%~99% | 严重滑脱，常需手术干预 |
| **V 度** | 滑移 ≥ 100% | 完全滑脱（椎体下垂），脊柱严重不稳 |

**Wiltse-Newman 病因分类**：

| 类型 | 名称 | 病因与特点 |
|------|------|-----------|
| **I 型** | 发育不良型 | 先天性腰骶关节面发育异常，L5-S1 多见，常伴脊柱裂 |
| **II 型** | 峡部型 | 椎弓峡部缺损或骨折；IIA=峡部溶解型；IIB=峡部延长型；IIC=急性峡部骨折型；L5-S1 最常见 |
| **III 型** | 退变型 | 小关节和椎间盘长期退变导致节段不稳；L4-L5 多见；中老年女性多见；无峡部缺损 |
| **IV 型** | 创伤型 | 高能量创伤致椎弓/关节突骨折（非峡部） |
| **V 型** | 病理型 | 肿瘤、感染、代谢性骨病等破坏椎弓结构 |
| **VI 型** | 医源型 | 术后广泛减压导致脊柱不稳 |

**6 要素标准化描述**：

| 要素 | 说明 |
|------|------|
| 基本特征 | 腰椎椎体滑脱，[Wiltse ? 型] 病因 |
| 解剖位置 | 腰n椎体相对于腰n+1 椎体 [向前/向后] 滑移 |
| 几何特征 | 滑移距离约 ?mm，滑移率约 ?%（Meyerding ? 度） |
| 影像特征 | [腰n双侧峡部骨质不连续/椎小关节退变增生/椎弓根骨折]；椎间盘退变（Pfirrmann ? 级）；椎小关节 [Weishaupt ? 级退变] |
| 继发改变 | 同节段椎管 [狭窄/明显狭窄]（Lee ? 级）；[左/右] 侧椎间孔 [狭窄]（Lee ? 级）；硬膜囊 [受压变形]；~神经根 [受压] |
| 时间变化 | 对比既往片，滑脱程度 [无进展/加重] |

**标准描述句式**：

```
[腰n椎体相对于腰n+1椎体向前滑脱约?%（Meyerding ?度，Wiltse ?型），伴腰n双侧峡部骨质不连续/椎小关节明显退变；同节段椎管中度/重度狭窄（Lee ?级），双侧椎间孔狭窄，硬膜囊受压变形，~神经根受压]
```

#### 2.3 椎体血管瘤

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体良性血管源性结节/占位，含脂肪、血管、增粗骨小梁混合结构 |
| 解剖位置 | 腰n椎体（前部\|\|中部\|\|后部），局限于椎体内，~不突破骨皮质、不累及椎弓根 |
| 几何特征 | 数量单发\|\|多发；大小约 ?cm×?cm；类圆形，边界清晰；内部栅栏状/竖行增粗骨小梁低信号分隔 |
| 影像特征 | T1WI 高信号（脂肪基质）、T2WI 明显高信号；STIR 序列仍呈高信号；增强后均匀轻中度强化；轴位呈"圆点征"，矢状位呈"栅栏征" |
| 继发改变 | ~无椎体塌陷、~无椎旁软组织肿块、~无椎管神经压迫；巨大侵袭性血管瘤可伴椎体膨大、皮质变薄 |
| 时间变化 | 对比既往片病灶大小、信号无进展\|\|较前增大 |

**标准描述句式**：

```
[腰n椎体内见类圆形病灶，大小约?cm×?cm，边界清晰；T1WI高信号、T2WI显著高信号，内见垂直走行增粗骨小梁低信号分隔（栅栏征），STIR序列病灶持续高信号；增强扫描病灶均匀轻度强化；病灶局限于椎体内，骨皮质完整，~无椎体压缩、~无椎旁软组织肿块、~无椎管狭窄及神经受压]
```

#### 2.4 椎体转移瘤（溶骨/成骨/混合型）

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体骨质破坏性占位，骨髓异常浸润，恶性肿瘤骨转移 |
| 解剖位置 | 单发腰n椎体\|\|多节段跳跃式椎体（腰n、腰m、骶1），常同时累及椎弓根（特征性征象） |
| 几何特征 | 不规则片状/团块状，边界模糊；多椎体多发；椎体可楔形变、塌陷；骨皮质连续性中断 |
| 影像特征 | T1WI 弥漫低信号（正常高信号骨髓完全替代）；T2WI 混杂高信号；STIR 大范围高信号；增强后不均匀中度～重度强化；成骨性转移 T1/T2 均低信号 |
| 继发改变 | 常伴椎旁软组织肿块，向后突入椎管致硬膜囊、马尾受压；椎间隙高度、终板多保留（与脊柱结核鉴别）；附件骨质同步破坏 |
| 时间变化 | 对比既往片病灶范围扩大、新增受累椎体、椎体塌陷进展 |

**标准描述句式**：

```
[腰n、腰m多节段椎体及双侧椎弓根骨髓正常信号消失，代之以不规则片状异常信号；T1WI低信号，T2WI混杂高信号，STIR序列大范围高信号；增强扫描病灶不均匀重度强化；腰n椎体骨皮质中断、轻度楔形变，椎体后方见软组织肿块突入椎管，硬膜囊受压、马尾神经聚集；椎间隙高度正常，终板无明显破坏]
```

#### 2.5 椎体压缩骨折（新鲜/陈旧，良恶性区分）

**Genant 半定量分型**：基于椎体高度减少百分比分级。

| 分级 | 程度 | 椎体高度减少 |
|------|------|-------------|
| **0 级** | 正常 | 椎体形态正常，无压缩 |
| **1 级** | 轻度 | 椎体高度减少 20%~25%，面积减少 10%~20% |
| **2 级** | 中度 | 椎体高度减少 26%~40%，面积减少 20%~40% |
| **3 级** | 重度 | 椎体高度减少 > 40%，面积减少 > 40% |

##### （1）新鲜良性骨质疏松性压缩骨折

| 要素 | 说明 |
|------|------|
| 基本特征 | 椎体骨质连续性中断、压缩变形，伴急性期骨髓水肿 |
| 解剖位置 | 腰n椎体前柱\|\|前中柱 |
| 几何特征 | 椎体前部楔形变（Genant ? 级），椎体高度减低约 ?%；可见线状低信号骨折线；骨皮质皱褶、轻微后缘骨块突入椎管 |
| 影像特征 | T1WI 骨折区弥漫低信号；T2WI、STIR 大范围高信号骨髓水肿；增强后骨折区片状轻度强化；椎弓根、附件信号正常 |
| 继发改变 | 椎旁软组织片状水肿高信号；~无椎旁实性肿块；椎间隙完好 |
| 时间变化 | 陈旧骨折水肿信号消退，骨髓信号恢复正常 |

**标准描述句式**：

```
[腰n椎体前部楔形变（Genant ?级），椎体高度减低约?%；椎体内见线状低信号骨折线，T1WI椎体骨髓弥漫低信号，T2WI、STIR序列大范围高信号水肿；增强扫描骨折区域轻度片状强化；椎体后缘少量骨块轻度突入椎管，硬膜囊轻微受压；椎旁软组织见水肿信号，双侧椎弓根信号正常，未见软组织肿块形成]
```

##### （2）恶性病理性压缩骨折（转移瘤继发）

> 椎体塌陷伴全椎体骨髓浸润、椎弓根破坏、椎旁软组织肿块，参考【椎体转移瘤】描述。

##### （3）良恶性压缩骨折 MRI 鉴别要点

| 鉴别要点 | 良性（骨质疏松性） | 恶性（病理性） |
|----------|-------------------|---------------|
| 骨髓信号 | 骨折线周围水肿，残留正常骨髓信号 | 全椎体弥漫异常信号，正常骨髓完全替代 |
| 椎弓根受累 | 少见，信号多正常 | 常见，椎弓根信号异常 |
| 椎旁软组织 | 水肿带，无实性肿块 | 软组织肿块形成 |
| 椎体后缘 | 皮质皱褶，无明显膨出 | 后缘膨隆、凸向椎管 |
| 增强模式 | 片状轻度强化 | 不均匀明显强化 |
| 其他椎体 | 骨质疏松背景 | 可见其他转移灶 |

#### 2.7 脊髓圆锥/终丝室管膜瘤（黏液乳头型为主）

| 1 | 腰椎退行性变 | `[腰椎退行性变：腰n-m椎间盘突出/膨出（Pfirrmann ?级，MSU ?级?区），伴多节段骨质增生、黄韧带增厚、椎管轻度/中度/重度狭窄（Lee ?级）、左/右侧椎间孔狭窄（Lee ?级）。建议结合临床症状定期腰椎MRI随访 \|\| 骨科门诊就诊]` |

| 3 | 椎体压缩骨折 | `[腰n椎体新鲜/陈旧压缩性骨折（Genant ?级），伴骨髓水肿、椎旁软组织水肿。建议骨科专科就诊，规范抗骨质疏松治疗，1~3月复查腰椎MRI评估水肿吸收情况]` |

### 范式 2：归纳式结论

> 适用场景：转移瘤、椎管内肿瘤、定性困难病灶。
>
> 格式：**客观基本征象** + **主观判读（1~3 个鉴别诊断）** + **合理建议**

**模板 1：椎体多发转移瘤**

```
[客观征象：腰n、腰m多椎体及椎弓根骨质破坏，伴椎旁软组织肿块、椎管狭窄、马尾受压]
[主观判读：①椎体多发转移瘤可能性大；②多发性骨髓瘤待鉴别；③淋巴瘤待排除]
[合理建议：结合全身肿瘤病史、骨扫描、肿瘤标志物检查，骨科/肿瘤科联合会诊]
```

**模板 2：椎管内神经源性肿瘤**

```
[客观征象：腰n-n+1椎管内哑铃形髓外硬膜下占位，椎间孔扩大]
[主观判读：①神经鞘瘤（良性）；②神经纤维瘤待鉴别]
[合理建议：神经外科会诊，评估手术切除指征]
```

**模板 3：圆锥终丝室管膜瘤**

```
[客观征象：T12-L3圆锥终丝区长条分叶状强化占位，伴帽征、脊髓空洞]
[主观判读：①黏液乳头型室管膜瘤；②椎管内神经源性肿瘤待鉴别]
[合理建议：神经外科就诊，完善全脊髓MRI排查软脊膜播散]
```

**模板 4：椎体压缩骨折（良恶性待定）**

```
[客观征象：腰n椎体压缩变扁，骨髓信号异常，伴椎旁软组织影]
[主观判读：①骨质疏松性压缩骨折可能性大；②病理性骨折（转移瘤）待排除]
[合理建议：结合肿瘤病史、骨密度检查、肿瘤标志物，必要时PET-CT或穿刺活检明确诊断]
```

**模板 5：椎旁肿块（性质待定）**

```
[客观征象：腰n水平椎旁见异常信号肿块，伴相邻椎体骨质改变]
[主观判读：①感染性病变（脊柱结核/化脓性脊柱炎）；②肿瘤性病变（转移瘤/淋巴瘤）；③神经源性肿瘤待鉴别]
[合理建议：结合临床症状、实验室检查（血常规、CRP、血沉、肿瘤标志物），必要时增强扫描或穿刺活检]
```

## 五、完整报告样例

### 样例 1：重度腰椎退行性变伴椎管狭窄（演绎式结论）

**影像描述**：

- **组织器官水平**：`[腰椎序列规整，腰骶椎生理曲度变直；全腰椎椎体广泛骨质增生]`
- **病灶病变水平**：
  - `[腰4-5椎间盘退变（Pfirrmann IV级），髓核脱水变性，椎间隙中度狭窄；椎间盘向后中央偏左脱出（MSU 2级B区），大小约8mm×6mm，硬膜囊明显受压变形，左侧神经根受压淹没；同节段椎管重度狭窄（Lee 3级），左侧椎间孔重度狭窄（Lee 3级）]`
  - `[腰5-骶1椎间盘退变（Pfirrmann III级），轻度膨出，硬膜囊轻度受压，椎管轻度狭窄（Lee 1级）]`
  - `[腰4-5双侧椎小关节退变（Weishaupt 2级），关节突增生肥大，黄韧带肥厚（厚度约5mm）]`
  - `[腰4、腰5椎体终板下见片状水肿信号（Modic I型），累及椎体高度约20%]`
- **图像区域水平**：`[扫描范围内双肾、骶髂关节、腹壁软组织未见异常偶然病灶]`

**诊断结论（演绎式）**：

```
[腰椎重度退行性变：腰4-5椎间盘脱出（MSU 2级B区），伴椎管重度狭窄（Lee 3级）、左侧椎间孔重度狭窄（Lee 3级）、左侧神经根受压；腰5-骶1椎间盘膨出，伴椎管轻度狭窄；多节段椎体骨质增生、椎小关节退变、黄韧带肥厚；腰4、腰5椎体终板炎（Modic I型）。建议：骨科专科就诊，结合临床症状评估手术指征；对症保守治疗无效时可考虑手术减压]
```

### 样例 2：腰椎峡部裂性滑脱（演绎式结论）

**影像描述**：

- **组织器官水平**：`[腰5椎体相对于骶1向前滑脱约30%（Meyerding II度），腰骶椎生理曲度加大]`
- **病灶病变水平**：
  - `[腰5双侧峡部骨质不连续（Wiltse IIA型，峡部裂性），断端见骨质硬化]`
  - `[腰5-骶1椎间盘退变（Pfirrmann IV级），椎间隙重度狭窄，椎间盘膨出]`
  - `[腰5-骶1节段椎管重度狭窄（Lee 3级），双侧椎间孔狭窄（Lee 2级），硬膜囊明显受压，马尾神经聚集]`
  - `[腰5-骶1双侧椎小关节退变（Weishaupt 2级）]`
- **图像区域水平**：`[扫描范围内未见明显异常偶然病灶]`

**诊断结论（演绎式）**：

```
[腰5椎体峡部裂性向前滑脱（Meyerding II度，Wiltse IIA型）：腰5双侧峡部骨质不连续；腰5-骶1椎间盘重度退变、椎间隙狭窄；腰5-骶1节段椎管重度狭窄（Lee 3级）、双侧椎间孔狭窄。建议：骨科脊柱专科就诊，评估滑脱稳定性及手术融合指征]
```

### 样例 3：椎体多发转移瘤（归纳式结论）

**影像描述**：

- **组织器官水平**：`[腰椎序列规整，生理曲度正常；腰1、腰3、腰5椎体正常骨髓信号广泛消失，其余椎体基线信号尚可]`
- **病灶病变水平**：
  - `[腰1、腰3、腰5多节段椎体及双侧椎弓根见不规则骨质破坏灶；T1WI弥漫低信号，T2WI混杂高信号，STIR大范围水肿高信号；增强后不均匀重度强化]`
  - `[腰3椎体楔形变（Genant 2级）、骨皮质中断，椎体后方软组织肿块突入椎管，硬膜囊、马尾神经聚集受压]`
  - `[椎间隙高度、终板结构保留；无椎间盘突出、黄韧带肥厚]`
- **图像区域水平**：`[扫描范围内肝脏见微小囊肿，双肾未见异常；骶髂关节无侵蚀改变]`

**诊断结论（归纳式）**：

```
[客观征象：腰1、3、5多椎体及椎弓根骨质破坏性病灶，伴椎旁软组织肿块、椎管狭窄、马尾神经受压]
[主观判读：①多发椎体转移瘤可能性高；②多发性骨髓瘤待鉴别；③淋巴瘤待排除]
[合理建议：结合原发肿瘤病史、全身骨扫描、肿瘤标志物及骨髓穿刺检查，肿瘤科+骨科联合会诊]
```

## 六、快速选词库

### 6.1 椎间盘病变选词

| 类别 | 可选描述词 |
|------|-----------|
| 退变程度 | Pfirrmann I 级（正常）、II 级（早期）、III 级（中度）、IV 级（重度）、V 级（终末期） |
| 突出类型 | 膨出（bulge）、突出（protrusion）、脱出（extrusion）、游离（sequestration） |
| 突出方向 | 中央型、旁中央型（左/右）、椎间孔型（左/右）、极外侧型（左/右）、前方型 |
| MSU 大小 | 1 级（未达 50%）、2 级（超过 50%）、3 级（超出小关节内线） |
| MSU 位置 | A 区（中央）、B 区（旁中央）、C 区（椎间孔） |
| Lee 迁移 | I 区（上移-椎弓根下缘）、II 区（上移-椎体水平）、III 区（下移-椎体上缘）、IV 区（下移-椎弓根水平） |

### 6.2 椎管狭窄选词

| 类别 | 可选描述词 |
|------|-----------|
| 中央管狭窄 | Lee 0 级（无）、1 级（轻度）、2 级（中度）、3 级（重度） |
| 椎间孔狭窄 | Lee 0 级（无）、1 级（轻度-双向脂肪消失）、2 级（中度-四向脂肪消失）、3 级（重度-神经根变形） |
| 侧隐窝狭窄 | 0 级（> 5mm）、1 级（3~5mm）、2 级（< 3mm）、3 级（神经根淹没） |

### 6.3 椎体与附件选词

| 类别 | 可选描述词 |
|------|-----------|
| 滑脱程度 | Meyerding I 度（< 25%）、II 度（25~49%）、III 度（50~74%）、IV 度（75~99%）、V 度（≥ 100%） |
| 滑脱病因 | Wiltse I 型（发育不良）、II 型（峡部裂性）、III 型（退变性）、IV 型（创伤性）、V 型（病理性）、VI 型（医源性） |

| 小关节退变 | Weishaupt 0 级（正常）、1 级（轻度）、2 级（中度）、3 级（重度） |
| 压缩骨折 | Genant 0 级（正常）、1 级（轻度 20~25%）、2 级（中度 26~40%）、3 级（重度 > 40%） |
| 黄韧带肥厚 | 正常（< 4mm）、轻度（4~5mm）、中度（5~7mm）、重度（> 7mm） |
