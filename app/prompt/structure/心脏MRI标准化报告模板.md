1. **整体基线水平**：心脏整体大小形态、心功能、图像质量、基线正常表现

##### （1）缺血性心肌病变（心肌缺血/陈旧性心梗/室壁瘤）

**心肌梗死组织水平分级（CCS 分级）**：

| 分级 | 说明 |
|------|------|
| CCS 1 级 | 中止型心梗，无/极小范围心肌坏死 |
| CCS 2 级 | 心肌细胞显著坏死，无微血管损伤 |
| CCS 3 级 | 心肌坏死 + 微血管梗阻（MVO，"无复流"） |
| CCS 4 级 | 心肌坏死 + MVO + 心肌内出血（IMH，出血性心梗） |

**透壁程度分级**：心内膜下（< 50% 壁厚）、透壁（> 75% 壁厚）

**心梗分期**：急性期（< 7 天，水肿 + LGE）、亚急性期（7 天 ~ 4 周，水肿消退中）、陈旧性（> 4 周，仅 LGE 无水肿）

| 要素 | 说明 |
|------|------|
| 基本特征 | 冠脉供血区域心肌继发性结构、功能损伤，急性病变伴水肿，陈旧性病变伴纤维化、室壁重塑、室壁变薄 |
| 解剖分布 | 左室…节段（冠脉供血对应区域），多累及心内膜下、透壁分布 |
| 几何形态 | 病变节段心肌变薄、轮廓僵硬，局部可向外膨隆形成室壁瘤 |
| 功能特征 | 病变节段运动减弱/消失/反向运动，收缩增厚率显著下降，整体 LVEF 降低 |
| 信号特征 | 急性期 T2WI 高信号、T2-mapping 数值升高（心肌水肿）；陈旧性病变对应节段见心内膜下/透壁 LGE 延迟强化，无水肿信号 |
| 继发改变 | 可伴局部微循环障碍（MVO）、心腔内血栓、远端血流灌注减低，多无心肌肥厚 |

**陈旧性心梗标准句式**：

```
[左室心底前壁、前间隔（1、2段）节段心肌变薄，收缩期无运动、增厚率显著降低；T2WI序列未见明显水肿信号，对应节段见透壁性LGE延迟强化，边界清晰，提示陈旧性心肌梗死；局部心室壁轻度膨隆，未见明确室壁瘤及心腔内血栓，邻近心肌运动同步性尚可]
```

**急性心梗伴 MVO 标准句式**：

```
[左室…节段见大范围T2高信号水肿，对应节段透壁性LGE强化，强化区内见无强化低信号区（MVO），提示急性心肌梗死（CCS ?级）；局部室壁运动消失，整体LVEF=?%；~伴心肌内出血（IMH）]
```

##### （2）肥厚型心肌病（非对称/对称/心尖肥厚型）

| 要素 | 说明 |
|------|------|
| 基本特征 | 心肌异常增生肥厚，无负荷增高诱因，常伴心肌中层纤维化、运动同步性异常 |
| 解剖分布 | 非对称型以室间隔基底段/中段肥厚为主；对称型左室整体向心性肥厚；心尖肥厚型局限于心尖 13-17 段 |
| 几何形态 | 肥厚节段心肌厚度 > 15mm，非对称型室间隔/侧壁厚度比值 > 1.3，心腔呈桃形/掐腰样改变 |
| 功能特征 | 肥厚节段收缩亢进，整体 LVEF 可增高；室间隔肥厚者可见 LVOT 射流征象，提示流出道梗阻 |
| 信号特征 | 肥厚心肌中层多见灶状、条片状 LGE 延迟强化，无大范围心内膜下强化；急性期无明显水肿 |
| 继发改变 | 可伴左房轻度扩张、二尖瓣 SAM 征、舒张功能减退，晚期可出现心功能下降 |

**标准描述句式**：

```
[左室室间隔基底段、中段（2、3、8、9段）非对称性肥厚，舒张末期最大厚度?mm，室间隔/侧壁厚度比值?；肥厚心肌收缩运动亢进，可见LVOT收缩期高速射流征象，提示流出道轻度/中度/重度梗阻；心肌中层见散在灶状LGE强化，无T2水肿信号；左房轻度扩张，瓣膜未见明显返流，右心结构功能正常]
```

##### （3）扩张型心肌病

| 要素 | 说明 |
|------|------|
| 基本特征 | 双室/左室为主心腔扩张、心肌弥漫性变薄，收缩功能广泛受损，伴心肌纤维化 |
| 解剖分布 | 左室全域受累，可累及右室，无节段性供血对应规律 |
| 几何形态 | 左室腔球形扩张，LVEDD 显著增大，心肌整体变薄、肌小梁增多 |
| 功能特征 | 全域心肌运动弥漫性减弱，收缩增厚率普遍降低，LVEF 显著下降（HFrEF），运动同步性差 |
| 信号特征 | 心肌中层、壁内散在多发线样、斑片状 LGE 强化，无透壁、心内膜下特征性梗死样强化 |
| 继发改变 | 常伴左右心房扩张、二尖瓣/三尖瓣功能性关闭不全，可合并少量心包积液、心腔内血栓 |

```

##### （4）病毒性心肌炎（急性/亚急性/陈旧性）

> **Lake Louise 标准**（心肌炎诊断）：满足以下至少 2 项即可诊断心肌炎：
> 1. T2WI/T2-mapping 信号增高（水肿）
> 2. 早期钆增强比值升高（EGER）
> 3. LGE 见非缺血性分布的局灶强化

| 要素 | 说明 |
|------|------|
| 基本特征 | 心肌炎性水肿、细胞浸润，后期残留纤维化，病变多累及心肌中层、心外膜下 |
| 解剖分布 | 左室侧壁、下壁、心尖段多发散在分布，无冠脉供血节段规律 |
| 几何形态 | 心肌厚度基本正常，无明显肥厚、变薄，心腔形态规整 |
| 功能特征 | 局部/全域心肌运动轻度减弱，运动同步性欠佳，轻症 LVEF 正常，重症可降低 |
| 信号特征 | 急性期病变节段 T2WI 高信号、T2-mapping 升高（水肿），伴中层/心外膜下片状 LGE 强化；陈旧期水肿消退，仅残留局限性 LGE 纤维化灶 |
| 继发改变 | 可伴少量心包反应性积液，无室壁瘤、心腔扩张 |

**标准描述句式**：

```
[左室侧壁、下壁（5、6、11、12段）见多发散在片状T2高信号影，提示心肌炎性水肿；对应节段心肌中层见斑片状LGE延迟强化，无透壁累及；局部心肌运动轻度减弱，整体心功能正常（LVEF=?%）；心包腔内见少量反应性积液，心腔形态正常，无血栓及瓣膜重度异常]
```

|------|------|
| 基本特征 | 心室壁僵硬度增加、舒张功能严重受限，收缩功能多正常，心肌间质纤维化/浸润 |

#### 2.4 心肌信号与组织特征（T1/T2 mapping、LGE、灌注）

##### （1）正常心肌信号

```
[全程心肌T1WI、T2WI信号均匀，T1-mapping、T2-mapping数值在正常范围；无异常心肌水肿、出血信号；未见局灶及弥漫性钆延迟强化（LGE）；静息心肌灌注均匀，无持续性低灌注缺损]
```

##### （2）T1/T2 mapping 正常参考值（1.5T，SCMR 共识）

| 参数 | 正常范围（1.5T） | 病理意义 |
|------|-----------------|----------|
| native T1 | 950 ~ 1050ms | 升高：水肿、淀粉样变、纤维化；降低：铁过载、出血 |
| post-contrast T1 | 450 ~ 550ms | 降低：纤维化/ECV 增加 |
| T2 | 49 ~ 55ms | 升高：心肌水肿、炎症 |
| ECV | 25% ~ 30% | 升高：弥漫性纤维化、淀粉样变、水肿 |

##### （3）心肌水肿与出血

```
[左室…节段心肌T2WI信号增高，T2-mapping数值升高（?ms），提示活动性心肌水肿；水肿区域内见线状短T2低信号影，提示合并心肌内出血（IMH）；病变分布非冠脉节段性/冠脉节段性，边界可模糊，无大范围透壁累及]
```

##### （4）心肌微循环障碍（MVO）

```
[左室…节段透壁性LGE强化区域内，见孤立性无强化低信号区，对应节段心肌运动明显减弱，提示心肌微循环灌注障碍；静息灌注序列对应区域持续性低灌注缺损]
```

##### （5）心肌灌注异常分级

| 分级 | 标准 |
|------|------|
| **0 级**（正常） | 无灌注缺损，心肌均匀强化 |
| **1 级**（轻度） | 心内膜下灌注缺损，< 50% 壁厚，累及 1~2 个节段 |
| **2 级**（中度） | 透壁性灌注缺损，> 50% 壁厚，累及 3~4 个节段；缺血范围 10%~19% LV 心肌 |
| **3 级**（重度） | 大范围透壁性灌注缺损，累及多支冠脉供血区；缺血范围 ≥ 20% LV 心肌 |

> 灌注缺损判断标准：持续 > 5 个心动周期的低信号区，心内膜下起始，呈冠脉分布特征。

##### （6）LGE 强化模式与病理意义

| LGE 模式 | 病理意义 |
|----------|----------|
| 心内膜下/透壁强化 | 缺血性心肌梗死（冠脉供血区分布） |
| 心肌中层强化 | 心肌病（DCM、HCM 纤维化）、心肌炎 |
| 心外膜下强化 | 心肌炎、心包炎累及 |
| 弥漫性壁内强化 | 扩张型心肌病、淀粉样变 |
| 局灶灶状强化 | 肥厚型心肌病纤维化灶 |
| 插入点强化 | 生理性/早期纤维化（室间隔与右室壁交界处） |

##### （7）心肌致密化不全

```
[左室中下段、心尖段肌小梁增多、粗大，呈双层结构，致密层变薄、非致密层增厚，非致密/致密层比值＞2；心腔内血流信号抑制不全，局部心肌运动减弱，无特征性LGE强化或伴少量灶状纤维化]
```

```

## 三、诊断结论（两套标准范式）

### 范式 1：演绎式结论

> 适用场景：有典型影像表现、无定性争议、临床/影像明确诊断。
>
> 基本格式：**明确诊断** + **核心 MRI 征象** + **合理建议**

| 模板 | 核心诊断 |
|------|----------|
| 模板 1 | 正常心脏 MRI |
| 模板 2 | 陈旧性心肌梗死 |
| 模板 3 | 肥厚型心肌病 |
| 模板 4 | 扩张型心肌病 |
| 模板 5 | 急性病毒性心肌炎 |
| 模板 6 | 心脏瓣膜病 |
| 模板 7 | 心包积液 |

#### 模板 1：正常心脏 MRI

```
[心脏MRI平扫+增强检查未见明显异常。核心征象：心肌结构、运动、信号无异常，全心收缩功能正常，瓣膜、心包、冠脉未见病理性改变。建议：常规年度体检随访]
```

#### 模板 2：陈旧性心肌梗死

```
[陈旧性前壁心肌梗死，局部心肌纤维化。核心征象：左室前壁节段透壁LGE强化，无活动性心肌水肿，局部室壁运动减弱，LVEF=?%。建议：心血管内科就诊，规范冠心病二级预防，6~12个月复查心脏MRI评估心肌状态]
```

#### 模板 3：肥厚型心肌病

```
[非对称性肥厚型心肌病，无/伴轻度流出道梗阻。核心征象：室间隔非对称性肥厚（最大厚度?mm），心肌中层灶状纤维化，LVOT无/有明显射流梗阻。建议：心血管专科随访，完善基因检测，年度复查心脏功能及结构]
```

#### 模板 4：扩张型心肌病

```
[扩张型心肌病，左室收缩功能减退（HFrEF）。核心征象：左室球形扩张，LVEF=?%，心肌壁内散在纤维化灶，二尖瓣轻度返流。建议：心血管内科规范心衰治疗，定期复查心功能，评估ICD植入指征]
```

#### 模板 5：急性病毒性心肌炎

```
[急性病毒性心肌炎。核心征象：左室多节段心肌水肿伴中层LGE强化，符合Lake Louise标准，心功能轻度受损，少量心包反应性积液。建议：心血管内科住院治疗，营养心肌、对症处理，3个月复查心脏MRI]
```

#### 模板 6：心脏瓣膜病

```
[主动脉瓣重度狭窄/二尖瓣重度关闭不全。核心征象：瓣叶增厚、钙化，瓣口面积?cm²/返流量?ml，伴左室肥厚/左房增大、心功能正常/减退。建议：心外科会诊，评估手术指征]
```

#### 模板 7：心包积液

```
[心包少量/中量/大量积液。核心征象：心包腔内液性信号，厚度约?cm，估测积液量约?ml，~心脏受压。建议：结合临床病因排查，必要时心包穿刺引流]
```

---

### 范式 2：归纳式结论

> 适用场景：恶性可疑、占位性质不典型、需鉴别良恶性。
>
> 基本格式：**客观基本征象** + **主观判读**（1~3 个鉴别诊断） + **合理建议**

#### 模板 1：心肌病变待查（心肌炎 vs 心肌病）

```
[客观核心影像征象：左室多节段心肌水肿伴中层LGE强化，心功能轻度受损，少量心包积液]
[鉴别诊断（概率由高至低）：①急性病毒性心肌炎；②自身免疫性心肌损伤待排除；③药物性/中毒性心肌损害待排]
[建议：心血管内科住院完善心肌酶、病毒学、自身抗体检查，对症营养心肌治疗，3个月复查心脏MRI评估心肌损伤恢复情况]
```

#### 模板 2：右室扩大待查

```
[客观核心影像征象：右室扩大、游离壁运动异常，右心功能下降，右室壁内纤维化灶]
[鉴别诊断：①致心律失常性右室心肌病（ARVC）；②慢性右心负荷增高继发改变待排除；③右室心肌致密化不全待排]
[建议：心内科电生理专科会诊，完善动态心电图、基因检测，短期随访]
```

#### 模板 3：左室肥厚待查

```
[客观核心影像征象：左室向心性肥厚，心肌弥漫性LGE强化，左房增大]
[鉴别诊断：①肥厚型心肌病；②心肌淀粉样变待排除；③高血压性心肌肥厚待排]
[建议：完善血清游离轻链、心脏超声应变分析，必要时心肌活检明确诊断，血液科/心内科联合就诊]
```

#### 模板 4：心腔内占位待查

```
[客观核心影像征象：左室/左房内见异常信号占位，大小约?cm，增强后轻度/明显强化]
[鉴别诊断：①心腔内血栓；②心脏黏液瘤；③心脏恶性肿瘤待排]
[建议：心脏超声+增强MRI联合评估，必要时心脏外科会诊，手术探查或活检明确诊断]
```

#### 模板 5：限制性心肌病待查

```
[客观核心影像征象：双心房显著扩大，心室壁厚度正常，收缩功能保留，舒张功能严重受限，心肌弥漫性LGE强化]
[鉴别诊断：①限制型心肌病；②缩窄性心包炎待排除；③心肌淀粉样变待排]
[建议：完善右心导管检查鉴别缩窄与限制，完善淀粉样变相关检查，心内科+心外科联合评估]
```

| T1 mapping | — | native T1 950~1050ms（1.5T） |
| T2 mapping | — | 49~55ms（1.5T） |
| ECV | — | 25%~30%（正常） |
| Lake Louise 标准 | 3 项 | 水肿 + 早期增强 + LGE，≥2 项阳性诊断心肌炎 |
| 图像质量分级 | 3 级 | 优质、合格、受限（SCMR 标准） |

## 五、完整报告样例

### 样例 1：正常体检心脏 MRI（演绎式结论）

**影像描述**：

- 整体基线水平：`[本次检查图像质量优质，心律整齐、呼吸配合良好，各序列成像清晰。心脏形态规整，房室比例协调，大血管连接正常]`
- 核心病灶与功能水平：
  - `[左、右心室心肌各节段厚度均匀，室壁运动同步协调，收缩增厚率正常]`
  - `[LVEF=62%，RVEF=58%，心功能参数正常（HFpEF范围）]`
  - `[全程心肌无水肿、出血信号，无异常LGE纤维化强化，心肌灌注均匀]`
  - `[各瓣膜开合良好，无狭窄、返流]`
  - `[心包光整，无增厚及病理性积液]`
  - `[冠脉主干无狭窄、硬化]`
- 邻近区域水平：`[扫描范围内双肺、纵隔、胸壁、大血管未见异常病变]`

**诊断结论（演绎式）**：

```
[心脏MRI平扫+增强检查未见明显异常。核心征象：心肌结构、运动、信号无异常，全心收缩功能正常，瓣膜、心包、冠脉未见病理性改变。建议：常规年度体检随访]
```

### 样例 2：急性病毒性心肌炎（归纳式结论）

**影像描述**：

- 整体基线水平：`[本次检查图像质量合格，心律基本整齐，轻微呼吸伪影不影响诊断。心脏整体形态规整，房室无明显扩张，大血管结构正常]`
- 核心病灶与功能水平：
  - `[左室侧壁、下壁多节段见片状T2高信号水肿影，T2-mapping值升高（58ms）]`
  - `[对应心肌中层见斑片状LGE延迟强化，无透壁累及及微循环障碍]`
  - `[局部心肌运动轻度减弱，整体LVEF=53%，心功能轻度受损（HFmrEF）]`
  - `[各瓣膜形态、运动基本正常，无明显返流、狭窄]`
  - `[心包腔内见少量反应性积液（厚度约0.6cm）]`
- 邻近区域水平：`[扫描范围内肺野、纵隔、胸壁未见异常合并病变]`

**诊断结论（归纳式）**：

```
[客观核心影像征象：左室多节段心肌活动性水肿伴中层纤维化，全心收缩功能轻度减低，少量心包反应性积液，符合Lake Louise心肌炎诊断标准]
[鉴别诊断：①急性病毒性心肌炎可能性大；②自身免疫性心肌损害待排除；③药物性心肌损害待排]
[建议：心血管内科住院完善心肌酶、病毒学、自身抗体检查，对症营养心肌治疗，3个月复查心脏MRI评估心肌损伤恢复情况]
```

### 样例 3：陈旧性心梗伴心衰（演绎式结论）

**影像描述**：

- 整体基线水平：`[本次检查图像质量优质。左室心腔轻度扩大，左房增大，右心结构基本正常]`
- 核心病灶与功能水平：
  - `[左室前壁、前间隔（1、2、7、8段）节段心肌变薄，收缩期无运动、增厚率消失]`
  - `[对应节段见透壁性LGE延迟强化，无T2水肿信号，提示陈旧性心肌梗死]`
  - `[LVEF=38%（HFrEF），左室整体收缩功能减退]`
  - `[二尖瓣轻度功能性返流，左房增大（横径45mm）]`
  - `[心包腔内见少量积液]`
- 邻近区域水平：`[扫描范围内双肺纹理增多，余未见明显异常]`

**诊断结论（演绎式）**：

```
[陈旧性前壁心肌梗死，左室收缩功能减退（HFrEF）。核心征象：左室前壁、前间隔透壁性LGE强化，无活动性水肿，局部室壁无运动，LVEF=38%，左房增大，二尖瓣轻度返流。建议：心血管内科规范冠心病二级预防及心衰治疗（ARNI/ACEI+β受体阻滞剂+MRA+SGLT2i），6个月复查心脏MRI评估心功能变化]
```
