# 报告模板的基本规则

## 1. 专用符号释义

| 符号 | 含义 |
|------|------|
| `、` | 并列可选描述术语 |
| `\|\|` | 意群二选一（逻辑"或"） |
| `&&` | 意群叠加补充（逻辑"且"） |
| `[]` | 用于分类、标题、提示、内容解释、诊断标准说明，**不纳入正式报告文本** |
| `项目符号` | 选填内容 |
| `数字序号` | 必填核心要素 |
| `…` | 解剖节段占位 |
| `n/m` | 序数填充 |
| `?` | 病灶测量数值 |
| `~` | 可删除修饰词（如 `~不`、`~其余`） |

## 2. 报告的基本构成

三大描述模块，按照顺序、缺一不可。

### 2.1 病灶病变水平（Lesion/Disease Level）

针对单个、同类多发的局灶病灶，一般需要明确以下 **6 个要素**：

#### 2.1.1 病灶的基本特征

尽量采用本科教材内各器官的基本病变用词或组合，例如：

- `肿块/占位`、`结节`、`实变`、`钙化`
- `囊性病变/囊实性病变`、`含气病变`
- `骨质破坏性病变`

能直接判读为某种病理改变的尽量采用：

- 如 `出血密度`、`肺气肿`、`骨折`

实在无准确用词的：

- `异常信号`、`异常密度`、`异常强化`、`结构紊乱`

#### 2.1.2 解剖位置和组织分布

按照解剖层级递进，尽可能精确。

- **位置**：一般是解剖区域 — `区` → `位` → `叶` → `段（回）` → `亚段` → `具体结构名称`
- **分布**：一般是按照某种特征，如按照血供分布、按照解剖分布、按照同类别组织分布等
  - 例如：`对称分布`、`灰质/白质`、`皮质/髓质`、`胸膜下区` 等

#### 2.1.3 几何特征

包括：**数量**、**大小**、**病灶形状**、**边缘**、**内部结构特征**。

- 平扫与增强后特征有明显差异的，需要各自描述
- 此部分象形词最多，也就是各种征象，需要规范化，部分象形词非常有特异性

#### 2.1.4 影像特征

密度或信号特征与测量值，包括：

- 增强的强化程度、强化形态
- 动态增强的时序变化
- 特殊扫描提供的信息如灌注、波谱等

#### 2.1.5 解剖与功能相关

与病灶和器官相关的结构与功能改变，例如：

- 侵犯、梗阻、扩张、功能不全
- 静脉曲张、引流区域淋巴结等继发改变

#### 2.1.6 时间变化

病灶与既往检查资料的比较变化。

---

### 2.2 组织器官水平（Organ/Tissue Level）

- 正常表现描述
- 相同组织器官的常见多发弥漫改变

多用于常见病如退行性病变，按照同类组织或同类结构分别进行描述。

---

### 2.3 图像区域水平（Imaging/Region Level）

- 扫描范围内与主病灶不十分相关的脏器清单
- 意外发现的病灶

## 3. 诊断结论

诊断结论有两种基本范式。

### 3.1 归纳式结论

> **基本格式**：`客观基本征象与重要的相关发现` + `主观判读` + `合理的建议`

适用于影像诊断任务，基本目标是发现病变和定性。根据征象推测诊断结论，主观性很强，存在医生个人判读差异。

#### 3.1.1 基本的客观征象

- **目标**：完成发现病变的任务目标
- 对应报告描述中病灶的基本特征
- 追加的重要发现必须是直接有诊断价值的、临床必须关切的内容，如：
  - 区域的淋巴结增大
  - 直接的结构侵犯
  - 血栓形成的危急值表现等

#### 3.1.2 主观判读

- **目标**：完成对病灶进行定性判读
- 按照概率顺序列举 1-3 个鉴别诊断
- 在 `炎症`、`肿瘤`、`外伤`、`畸形` 的大类下，尽量做下一级的分类判读，例如：

| 大类 | 子分类 |
|------|--------|
| 炎症 | 感染性炎症、非感染性炎症、特异性感染（结核、霉菌） |
| 肿瘤 | 良性肿瘤、恶性肿瘤、良性或低度恶性病变、肿瘤样病变 |

- 实在定性判读困难的，也可以明确表达"定性困难"
- 影像诊断不建议不做病理级别的判读，如果达到病理学的判读信心可以用 `（）` 另行标注

#### 3.1.3 合理建议

建议的指向性尽量明确具体：

- 结合临床病史（外伤史、手术史、用药史等）
- `||` 结合既往或其他影像学检查
- `||` 结合临床实验室检查
- `||` 建议定期随访
- `||` 建议抗炎治疗后复查
- `||` 建议…学科会诊等

---

### 3.2 演绎式结论

> **基本格式**：`关键征象的列举` + `符合"明确的诊断"` + `合理的建议`
>
> 或：`"明确的诊断"` + `关键征象的列举` + `合理的建议`

适用于有明确的临床和/或病理诊断的、治疗前后的、典型的常见病病灶评估。

#### 3.2.1 明确的诊断

- 有明确的临床和/或病理诊断的，可以报告"符合…改变"
- 尽量按照常用的、广泛认可的标准给出各种分级、分期、分类
- 如果影像和临床病理诊断不符的，需要提出质疑
- 各种直观呈现无需主观推测的临床诊断，如：
  - 外伤后的创伤表现（骨折、血肿）
  - 常见疾病（脊柱的退行性变、颅脑的白质高信号分级）
- 治疗前后的、术后改变，需要给出关键的变化或临床关注的内容，例如：
  - 栓塞后的血供
  - 化疗后的分级判读（CR、PR、SD、PD）

#### 3.2.2 关键征象的列举

- 与病灶相关的重要表现
- 对临床的重要提示
- 超出原病灶的发现
- 危急值等

#### 3.2.3 合理建议

建议的指向性尽量明确具体：

- 结合临床病史（外伤史、手术史、用药史等）
- `||` 结合既往或其他影像学检查
- `||` 结合临床实验室检查
- `||` 建议定期随访
- `||` 建议抗炎治疗后复查
- `||` 建议…学科会诊等
